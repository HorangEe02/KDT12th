## 1. 프로젝트를 수행하게 된 이유

### 1.1 산업 환경의 변화: 제조업 AI 시대의 도래

제조 분야 AI 시장은 2023년부터 2028년까지 **연간 45.6%의 고속 성장**이 전망되고 있으며, 그 중에서도 **컴퓨터 비전** 기술이 다른 AI 기술 대비 가장 높은 성장률을 기록할 것으로 예측되고 있다. (출처: Markets and Markets, CIO Korea)

글로벌 산업용 머신 비전 카메라 시장 역시 2025년 약 22.9억 달러에서 **연평균 9.55% 성장**하여 2035년 57.1억 달러에 이를 것으로 전망된다. 특히 AI 기반 비전 카메라의 배포가 급증하면서 **수동 검사 오류가 40% 감소**하는 성과를 보이고 있다. (출처: Global Growth Insights)

자동 광학 검사(AOI) 시스템 시장은 **CAGR 18.3%**로 2025년 17.5억 달러에서 2035년 93.9억 달러까지 확대될 전망이다.

### 1.2 한국 제조업의 디지털 전환 흐름

2026년 국내 AI 시장은 전년 대비 25% 증가한 약 **6조 4,190억 원** 규모에 달할 것으로 전망되며, 제조업에서는 **스마트 팩토리 구축, 공정 자동화, 불량품 식별, 예지 보수** 등의 지능화 활동이 활발할 것으로 예측된다. (출처: KRG, CIO Korea)

### 1.3 왜 이 프로젝트인가?

**첫째, 교육과정과의 완벽한 정합성.** 본 프로젝트의 5가지 소주제(ROI 추출, 필터링/샤프닝, 에지/윤곽선 분석, 하이브리드 분류, 대시보드)는 컴퓨터 비전 프로그래밍 강의 1~4차시의 핵심 내용을 실무 파이프라인으로 연결한다.

**둘째, 대규모 실전 데이터셋 도전.** Phase9(NEU 1,800장)에서 Phase9_v2(Severstal 150,816 패치)로 확장하여, 실제 산업 규모의 데이터 처리 파이프라인을 경험한다.

**셋째, 교차 도메인 검증.** 단일 데이터셋 성능을 넘어, Severstal→NEU 교차 검증을 통해 모델 일반화의 한계와 도메인 적응의 필요성을 실증한다.

## 3. 데이터셋

### 3.1 메인 데이터셋: Severstal Steel Defect Detection

| 항목                  | 내용                                                                 |
| --------------------- | -------------------------------------------------------------------- |
| **출처**        | Kaggle -- Severstal Steel Defect Detection Competition               |
| **링크**        | https://www.kaggle.com/competitions/severstal-steel-defect-detection |
| **원본**        | Severstal (러시아 최대 철강 기업)                                    |
| **원본 이미지** | 12,568장 (256 x 1,600 픽셀, 강철 스트립 전체 촬영)                   |
| **패치 변환**   | 256 x 1,600 → 256 x 256 패치로 분할 (1장당 12패치, stride=128, 50% 오버랩)                |
| **총 패치 수**  | **150,816장** (Normal 120,583 + Defect 30,233)                   |

### 3.2 결함 유형 (4클래스)

| ClassId | 약칭 | 한국어명  | 설명                           |
| ------- | ---- | --------- | ------------------------------ |
| 1       | PS   | 점상 결함 | 점 형태의 미세 표면 결함       |
| 2       | LS   | 선형 긁힘 | 선형의 긁힘 또는 스크래치 자국 |
| 3       | SS   | 표면 변색 | 불균일한 색상 변화 영역        |
| 4       | RD   | 압연 압흔 | 압연 공정에서 발생한 눌림 자국 |

### 3.3 데이터 분포

```
전체 패치: 150,816장
├── Normal (정상):  120,583장 (79.9%)
└── Defect (결함):   30,233장 (20.1%)
    ├── ClassId 1 (PS): 점상 결함    2,638장
    ├── ClassId 2 (LS): 선형 긁힘      457장
    ├── ClassId 3 (SS): 표면 변색   23,408장
    └── ClassId 4 (RD): 압연 압흔    3,730장
```

### 3.4 교차 검증 데이터셋: NEU-DET

| 항목                | 내용                                               |
| ------------------- | -------------------------------------------------- |
| **출처**      | NEU Surface Defect Database (동북대학교, 중국)     |
| **이미지 수** | 1,800장 (6클래스 x 300장)                          |
| **활용 방식** | Severstal 학습 모델의 교차 도메인 일반화 성능 검증 |

### 3.5 데이터셋 선정 이유

1. **대규모 산업 데이터**: 150,816 패치로 실전 규모의 데이터 처리 파이프라인 경험
2. **2-Stage 파이프라인 적합**: 정상/비정상 이진 분류 → 4종 결함 세부 분류의 자연스러운 구조
3. **클래스 불균형 학습**: SS(23,408)와 LS(457)의 약 51배 차이로 불균형 처리 전략 실습
4. **교차 도메인 검증**: NEU-DET와의 비교로 모델 일반화 한계 실증
5. **산업 신뢰성**: Kaggle 유명 Competition 데이터셋으로 학술/산업 벤치마크 활용

## 4. 시스템 아키텍처: 2-Stage 파이프라인

### 4.1 전체 흐름

```
[입력] 강철 스트립 이미지 (256 x 1,600)
   │
[패치 분할] 256 x 256 패치로 분할
   │
[전처리] CLAHE, Bilateral Filter, Sharpening, Morphology
   │
[특징 추출] HOG, LBP, Pixel Stats, Contour, Edge Pipeline
   │
[Stage 1] 이진 분류 (정상 vs 비정상)
   │        ML: VotingEnsemble 73.00%  |  DL: ResNet-18 FT 90.87%
   │
   ├── 정상 → 통과
   └── 비정상 →
         │
      [Stage 2] 4종 결함 분류
               ML: LightGBM 77.72%  |  DL: ResNet-18 FT 86.01%
               │
            [출력] 결함 유형 + 신뢰도

[이상 탐지] Autoencoder (AUROC 0.7023, Recall 96.0%)
            → Stage 1 보조 게이트로 활용
```

### 4.2 3단계 하이브리드 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│  Phase 1: 전통 ML 파이프라인                                  │
│  OpenCV 전처리 → HOG/LBP 특징 → ML 7종 분류                  │
│  (VotingEnsemble 73.00%, SVM, RF, KNN, MLP, XGBoost, LightGBM) │
└──────────────────────────┬──────────────────────────────────┘
                           │
    ▼                      ▼
┌─────────────────────┐  ┌──────────────────────────────────┐
│  Phase 2: 딥러닝     │  │  Phase 3: 이상 탐지               │
│  ResNet-18           │  │                                   │
│  FT: 90.87%          │  │  Autoencoder (50 epochs)           │
│  FE: --              │  │    AUROC 0.7023                    │
│  + Grad-CAM          │  │    Recall 96.0%                    │
│                      │  │    보조 게이트 역할                 │
└──────────┬──────────┘  └──────────────┬───────────────────┘
           │                            │
           ▼                            ▼
┌─────────────────────────────────────────────────────────────┐
│  Streamlit 8탭 대시보드 (주간/야간 자동 전환)                  │
│  결함분석 | Stage1 | Stage2 | 이상탐지 | 교차검증 |           │
│  시스템성능 | 딥러닝(NEU) | 통합비교                           │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 모델 성능 요약

#### Stage 1: 이진 분류 (정상/비정상)

| 계열 | 모델                   | Accuracy         | 비고              |
| ---- | ---------------------- | ---------------- | ----------------- |
| ML   | **VotingEnsemble** | **73.00% (AUC 0.7916)** | ML 최고 성능      |
| DL   | **ResNet-18 FT** | **90.87%** | Fine-Tuning, 최고 |

#### Stage 2: 4종 결함 분류

| 계열 | 모델                   | Accuracy         | 비고               |
| ---- | ---------------------- | ---------------- | ------------------ |
| ML   | **LightGBM**     | **77.72%** | ML 최고 성능       |
| DL   | **ResNet-18 FT** | **86.01%** | Fine-Tuning |

#### 이상 탐지 (Anomaly Detection)

| 모델        | AUROC  | Recall | F1     | 비고                                     |
| ----------- | ------ | ------ | ------ | ---------------------------------------- |
| Autoencoder | 0.7023 | 96.0%  | 0.7442 | 50 epochs, 보조 게이트 (20ep→50ep 향상) |

## 13. 교차 도메인 검증

Severstal 데이터셋으로 학습한 모델의 도메인 일반화 능력을 NEU-DET 데이터셋으로 검증하였다.

### 13.1 검증 결과

| 항목                           | 값                |
| ------------------------------ | ----------------- |
| Severstal 내 성능 (Stage 1 DL) | 90.87%            |
| NEU-DET 적용 성능 (DL Recall)  | 14.4%             |
| NEU-DET 적용 성능 (ML Recall)  | 51.6%             |
| **도메인 갭 (DL)**       | **-76.47%p** |

### 13.2 도메인 갭 분석

Severstal(256x1600, 강철 스트립)과 NEU(200x200, 열연 강판)는 동일한 금속 표면 결함 도메인이지만, 촬영 조건, 해상도, 결함 유형 체계가 상이하다. -76.47%p의 도메인 갭은 **단일 데이터셋 학습만으로는 교차 도메인 일반화가 불가능**하다는 것을 정량적으로 증명한다.

### 13.3 핵심 발견

1. **ML이 DL보다 교차 도메인에서 상대적으로 우수 (51.6% vs 14.4%)**: 수작업 특징(텍스처, 통계량)은 도메인에 덜 종속적
2. **DL(ResNet-18)은 Severstal 특유의 패턴에 과적합**: 일반화 실패
3. **모델 구조의 문제가 아님**: 동일 ResNet-18이 NEU 독립 학습 시 **100% 정확도** 달성
4. **실무 시사점**: 새로운 제조 환경 배포 시 **도메인 적응(Domain Adaptation)** 필수

### 13.4 합성 변형 강건성 테스트 (NB11b)

동일 Severstal 결함 패치에 7가지 합성 변형(밝기±30%, 노이즈, 블러, 대비, 해상도 열화)을 적용하여
**촬영 조건 변화에 대한 모델 내성**을 검증하였다.

| 강건성 지표 | ML (LightGBM) | DL (ResNet-18) |
|-----------|-------------|---------------|
| 기준선 Recall | 69.0% | 94.5% |
| 강건성 점수 (변형 평균/기준) | **86.5%** | **80.6%** |
| 최저 Recall | 53.5% (블러) | 55.5% (블러) |
| 최대 하락폭 | -15.5%p | -39.0%p |

**핵심**: DL이 원본 성능은 압도적이지만, 환경 변화 시 하락폭이 더 큼. NB11의 도메인 전이 결과(ML > DL)와 일관된 패턴.

## 14. 핵심 분석 전략

### 14.1 2-Stage 파이프라인 효과 검증

| 단계    | 역할             | 지표          | 기대 효과           |
| ------- | ---------------- | ------------- | ------------------- |
| Stage 1 | 이진 분류 (Gate) | Accuracy      | 정상/비정상 필터링  |
| Stage 2 | 4종 분류 (Type)  | Accuracy, F1  | 결함 유형 세부 식별 |
| AE Gate | 이상 탐지 보조   | AUROC, Recall | 미지의 결함 탐지    |

### 14.2 ML vs DL 정량 비교

ML 7종(전통 특징 기반)과 DL 2종(자동 특징 학습)을 동일 데이터셋에서 비교하여 **전이 학습의 실질적 효과**를 정량 증명:

- Stage 1: ML 73.00% → DL 90.87% (+17.87%p)
- Stage 2: ML 77.72% → DL 86.01% (+8.29%p)

### 14.3 제조업 맥락 평가 지표

- **False Negative (불량 → 정상 오판)**: 불량품 출하 → **치명적**
- **False Positive (정상 → 불량 오판)**: 생산성 손실 → **비용 손실**
- 따라서 **Recall(재현율) 우선** 전략이 합리적

#### 잘한 점

1. **2-Stage 파이프라인 설계**: 이진 분류(Gate) → 결함 분류(Type) 구조로, 실제 제조 라인의 "불량 선별 → 유형 판별" 흐름을 반영
2. **교차 도메인 + 강건성 이중 검증**: NEU-DET로 도메인 전이 한계를, 합성 변형으로 동일 도메인 강건성을 분리 검증
3. **50% 오버랩 패치 전략**: stride=128로 경계부 결함 누락 방지, 패치 수 증가 대비 효과 확인
4. **일관된 버전 관리**: v3.0 → v6.0까지 단계적 확장, 변경 이력 체계적 기록

#### 아쉬운 점 및 개선 방향

1. **DL 교차 도메인 14.4%**: Domain Adaptation(DANN, MMD) 기법으로 개선 가능
2. **클래스 불균형**: SS(23,408) vs LS(457) 약 51:1 불균형 → Focal Loss, SMOTE 미적용
3. **Stage 1 ML 73.00%의 한계**: DL(90.87%) 대비 크게 낮아 ML 단독 운용은 한계

### 15.2 프로젝트를 통해 느낀 점

#### 기술적 인사이트

| 인사이트 | 근거 | 시사점 |
|---------|------|--------|
| **데이터가 모델을 이긴다** | 같은 ResNet-18이 Severstal 90.87%, NEU 100% | 데이터 품질/대표성이 아키텍처보다 중요 |
| **전이 학습의 양면성** | ImageNet 가중치가 교차 도메인에서 편향으로 작용 | 도메인 간 전이 시 추가 적응 필수 |
| **이상 탐지의 실용적 가치** | Recall 96.0% = 불량 100개 중 96개 포착 | 라벨링 비용 높은 현장에서 One-Class 학습이 대안 |
| **ML의 도메인 범용성** | 교차 도메인에서 ML(51.6%) > DL(14.4%) | HOG/LBP 수작업 특징이 도메인 종속성이 낮음 |

#### 프로젝트 관리 관점

1. **체계적 버전 관리**: v3.0 → v6.0까지 변경 이력 기록이 프로젝트 연속성과 재현성 보장
2. **일관된 파이프라인 설계**: 전처리 → 특징 추출 → 학습 → 평가 → 시각화 흐름이 12개 노트북에 유지
3. **대시보드의 가치**: 코드와 수치로 전달되지 않는 인사이트를 비전공자에게 직관적으로 전달

## 21. 부록: 예상 Q&A

| 질문                                     | 답변 방향                                                                                                                               |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| "왜 NEU에서 Severstal로 변경했는가?"     | NEU 1,800장은 과적합이 쉬움(DL 100% 달성). Severstal 150K 패치는 실전 규모의 도전적 데이터셋이며, 2-Stage 파이프라인 설계에 적합         |
| "교차 도메인 검증의 의의는?"             | 단일 데이터셋 고성능이 실무 적용을 보장하지 않음을 -76.47%p 도메인 갭으로 실증. 도메인 적응 필요성의 정량적 근거 확보                    |
| "왜 ML이 DL보다 교차 검증에서 우수한가?" | ML은 수작업 특징(HOG, LBP 등 텍스처 통계)을 사용하여 도메인에 덜 종속적. DL은 Severstal 고유 패턴에 과적합                              |
| "AE AUROC 0.7023이 낮지 않은가?"         | 단독 분류기로는 부족하나, Stage 1 보조 게이트(Recall 96.0%)로 활용하면 불량 놓침률 4.0%로 실용적                                        |

| "왜 Streamlit을 선택했는가?"             | Python 기반으로 OpenCV/ML/DL과 즉시 연동 가능하고, 1.5일 내 8탭 프로토타입 완성이 가능한 유일한 선택지                                  |
