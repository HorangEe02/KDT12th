# 기능 설명서: 오늘 뭐 하지? (Stage 3 — 전(轉))

> AI 트레이너와 대화하면서 나만의 일주일 운동 계획을 세우고, 상세 루틴을 확인하는 기능

---

## 1. 기능 개요

"오늘 뭐 하지?"는 헬창지피티의 세 번째 단계로, Stage 1 프로필(목표, 경험, 제약사항)과 Stage 2 식단 정보를 바탕으로 **7일 운동 계획을 설계**합니다. AI 트레이너 챗봇과 대화하면서 루틴을 만들고, 부상 부위 대체 운동을 추천받고, 시간 제한에 맞춘 단축 루틴을 요청할 수 있습니다.

### 핵심 가치
- 사용자의 주당 운동 가능 횟수에 맞춰 7일(운동일+휴식일) 계획 자동 생성
- 부상/제약사항이 있는 부위의 운동을 자동으로 대체 운동으로 교체
- 각 운동마다 세트/반복/쉬는 시간 + 대체 운동 2개 + 수행 방법 설명 제공
- **⚠️ 면책 문구를 최상단에 배치** — AI 추천은 참고용이며, 본인 체력에 맞게 자유롭게 조정 안내

## 2. 면책 안내 문구

페이지 **최상단**에 항상 표시됩니다:

> ⚠️ AI 추천 루틴은 참고용이며, 정답이 아닐 수 있습니다. 본인의 체력 수준과 건강 상태에 맞게 운동 방법·강도·횟수를 자유롭게 조정하세요. 통증이나 불편함이 있으면 즉시 중단하고 전문가와 상담하세요.

## 3. 페이지 구성 (2탭)

### 3-1. AI 트레이너 탭

AI 트레이너 챗봇과 대화하면서 운동 루틴을 설계하고 조정합니다.

**챗봇 기능:**

| 사용자 입력 | AI 동작 |
|-----------|--------|
| "일주일 운동 계획 짜줘" | 프로필의 주당 운동 횟수(예: 3회)에 맞춰 7일 계획 생성 |
| "오늘 상체 운동 추천해줘" | 당일 상세 루틴 (웜업+메인+쿨다운) |
| "30분밖에 시간이 없어" | 시간 맞춤 단축 루틴 |
| "무릎이 아파서 하체 운동 대체해줘" | 제약 부위 제외 + 대체 운동 추천 |
| "오늘은 가볍게 하고 싶어" | 강도 낮춘 루틴 |

**프로필 자동 연동:**
- 주당 운동 횟수 → 7일 중 운동일/휴식일 배분
- 운동 목표 → 유산소/무산소 비율 결정
- 경험 수준 → 세트 수/반복 수/휴식 시간 조정
- 제약사항 → 해당 부위 운동 자동 교체

**처리 흐름:**
```
AI 대화 → POST /api/v1/workout/chat (LLM 응답)
       → [WORKOUT_PLAN] 태그 감지 시 루틴 자동 반영
       → "상세 루틴 보기" 탭으로 자동 전환
```

## 4. 핵심 기능 상세

### 4-1. 운동 분할 방식 자동 결정

사용자의 주당 운동 횟수와 경험 수준에 따라 분할 방식을 자동 결정합니다.

| 주당 횟수 | 입문/초급 | 중급 이상 |
|---------|---------|---------|
| 1회 | 전신 | 전신 |
| 2회 | 전신 | 상하분할 |
| 3회 | 전신 | 전신 |
| 4회 | 전신 | 상하분할 |
| 5회 | PPL+상하 | PPL+상하 |
| 6회 | PPL | PPL |
| 7회 | 부위별분할 | 부위별분할 |

> 입문/초급자는 주 4회까지 전신 운동을 권장합니다 (근육 회복 및 동작 학습 우선)

### 4-2. 목표별 유산소/무산소 비율

| 목표 | 유산소 | 무산소 | 설명 |
|------|--------|--------|------|
| 체지방감소 | **40%** | 60% | 유산소 비중 높여 지방 연소 극대화 |
| 근력증가 | 15% | **85%** | 근력 위주, 유산소는 마무리용 |
| 체력향상 | **50%** | 50% | 유산소와 근력 균형 |
| 체중관리 | 35% | **65%** | 기초대사량 유지 |
| 건강개선 | **45%** | 55% | 심폐 기능 + 관절 부담 적은 운동 |

### 4-3. 제약사항/부상 대체 운동

부상이 있는 부위의 운동을 자동으로 안전한 대체 운동으로 교체합니다.

| 제약사항 | 제외 운동 | 대체 운동 |
|---------|---------|---------|
| **무릎 부상** | 스쿼트, 런지 | 레그프레스(부하 조절), 힙 브릿지, 사이클 |
| **허리 부상** | 데드리프트, 바벨 로우 | 시티드 머신 로우, 랫풀다운, 데드버그(코어) |
| **어깨 부상** | 오버헤드 프레스, 벤치프레스 | 월 푸쉬업, 사이드 레터럴 레이즈(가볍게) |

### 4-4. 운동 상세 정보

각 운동에 포함되는 정보:

| 항목 | 설명 | 예시 |
|------|------|------|
| 운동명 | 한국어 + 영문 | 푸쉬업 (Push-up) |
| 목표 근육 | 주동근 | 가슴 |
| 보조 근육 | 보조근 | 삼두, 전면 어깨, 코어 |
| 세트 수 | 경험별 상이 | 입문 3세트 / 고급 4세트 |
| 반복 횟수 | 경험별 상이 | 입문 5~10회 / 고급 20+회 |
| 쉬는 시간 | 세트 간 휴식 | 30~90초 |
| 강도 | 저/보통/높음 | 보통 |
| 수행 방법 | 상세 설명 | "팔꿈치를 45도로 유지하며..." |
| 대체 운동 | 2개 | 무릎 푸쉬업, 인클라인 푸쉬업 |
| 주의사항 | 부상 관련 경고 | "어깨 통증 시 즉시 중단" |
| 장비 | 필요 장비 | 맨몸 / 바벨, 벤치 |
| MET 계수 | 칼로리 계산용 | 3.8 |

### 4-5. 운동 검색 (3가지 방식)

| 방식 | 엔진 | 강점 | 예시 |
|------|------|------|------|
| **BM25 키워드** | rank_bm25 | 자연어 질의 이해 | "무릎에 부담 적은 하체 운동" |
| **필터 검색** | DB 직접 매칭 | 정확한 부위/장비 매칭 | "가슴", "맨몸" |
| **임베딩 검색** | sentence-transformers | 의미 기반 유사도 | "전신 폭발적인 운동" |

**검색 비교 결과:**

| 질의 | BM25 | 필터 | 우수 |
|------|------|------|------|
| "하체 운동 추천" | 사이클, 트레드밀, 버피 | 스쿼트, 레그프레스, 런지 | 필터 |
| "유산소 심폐 체력" | 러닝, 줄넘기, 사이클 | (빈 결과) | **BM25** |
| "무릎에 부담 적은" | 덤벨플라이, 사이클 | (제약 필터링) | **BM25** |

→ **하이브리드 검색 (필터 + BM25) 권장**

### 4-6. 루틴 균형 분석

생성된 루틴의 품질을 자동 평가합니다.

| 분석 항목 | 방법 | 기준 |
|---------|------|------|
| 근육군 커버리지 | 7개 주요 근육군 중 운동한 부위 | 커버율 높을수록 점수 ↑ |
| 근육군 균형 | 부위별 세트 수 편차 | 균등할수록 점수 ↑ |
| 유산소/무산소 비율 | 목표 비율 대비 오차 | 목표 비율 ±15% 이내 적절 |
| 볼륨 평가 | 부위당 주간 세트 수 | 경험별 권장 세트 수 비교 |
| 제약사항 위반 | 금지 운동 포함 여부 | 위반 시 감점 |

**경험별 주당 권장 세트 수 (부위당):**

| 경험 | 최소 | 최대 |
|------|------|------|
| 입문 | 6 | 10 |
| 초급 | 8 | 12 |
| 중급 | 10 | 16 |
| 고급 | 14 | 22 |
