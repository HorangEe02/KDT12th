# 기능 설명서: 내 몸 알기 (Stage 1 — 기(起))

> 사용자의 신체 정보를 입력받아 AI가 분석하고, 맞춤형 건강 프로필을 생성하는 기능

---

## 1. 기능 개요

"내 몸 알기"는 헬창지피티의 첫 번째 단계로, 사용자의 신체 정보를 **4가지 방법**으로 입력받아 구조화된 프로필을 생성합니다. 이 프로필은 이후 식단(Stage 2), 운동(Stage 3), 피드백(Stage 4) 기능의 기반 데이터가 됩니다.

### 핵심 가치
- 운동을 처음 시작하는 사람도 쉽게 자신의 신체 상태를 파악할 수 있도록 지원
- AI가 BMI, 기초대사량, 권장 칼로리 등을 자동으로 계산하여 제공
- 인바디 결과지를 업로드하면 비전 AI가 자동으로 수치를 읽어 분석

---

## 2. 4가지 입력 방식

### 2-1. 직접 입력하기 (양식 폼)

**설명:** 구조화된 폼에 신체 정보를 직접 입력합니다.

**입력 항목:**

| 항목 | 유형 | 필수 | 설명 |
|------|------|------|------|
| 이름 | 텍스트 | 선택 | 사용자 이름 |
| 나이 | 숫자 | **필수** | 만 나이 |
| 성별 | 선택 (남/여) | **필수** | 버튼 토글 |
| 키 (cm) | 숫자 | **필수** | 소수점 지원 |
| 몸무게 (kg) | 숫자 | **필수** | 소수점 지원 |
| 체지방률 (%) | 숫자 | 선택 | 인바디 측정값 |
| 운동 목표 | 5개 중 택1 | **필수** | 이모지 카드로 선택 |
| 주당 운동 횟수 | 1~7 | 선택 | 드롭다운 (기본: 3) |
| 운동 경험 | 4단계 | 선택 | 입문/초급/중급/고급 |
| 제약사항 | 다중 선택 | 선택 | 무릎/허리/어깨/당뇨/고혈압 등 7종 |

**운동 목표 옵션:**

| 이모지 | 목표 | 설명 |
|--------|------|------|
| 🔥 | 살 빼기 (체지방 감소) | 체지방률을 낮추고 싶은 경우 |
| 💪 | 근육 키우기 (근력 증가) | 근육량을 늘리고 싶은 경우 |
| 🏃 | 체력 올리기 (스태미나) | 기초 체력/지구력을 높이고 싶은 경우 |
| ⚖️ | 현재 몸매 유지 | 체중을 유지하면서 관리하고 싶은 경우 |
| ❤️ | 건강 관리 (질환 등) | 당뇨, 고혈압 등 건강 관리를 위한 경우 |

**처리 흐름:**
```
폼 입력 → POST /api/v1/profile/save (저장)
       → POST /api/v1/profile/calculate-metrics (지표 계산)
       → BMI, BMR, TDEE, 권장 칼로리 즉시 표시
```

**사용된 NLP/계산 기법:**
- Mifflin-St Jeor 공식 (BMR 계산) — ADA 권장, Harris-Benedict 대비 현대 인구에서 더 정확
- KSSO(대한비만학회) BMI 6단계 판정 (저체중/정상/과체중/1~3단계 비만)
- TDEE = BMR × 활동 계수 (주당 운동 횟수 기반)
- 목표별 칼로리 조정 (체지방감소: -500kcal, 근력증가: +300kcal 등)

---

### 2-2. 인바디 사진/정보 올리기

**설명:** 인바디 결과지 파일을 업로드하면 AI가 자동으로 수치를 읽고 분석합니다.

**지원 파일 형식:**

| 형식 | 파싱 방법 | 설명 |
|------|---------|------|
| PNG, JPG | Ollama 비전 모델 (gemma4:e4b) | LLM이 이미지에서 수치를 읽음 |
| CSV | pandas 직접 파싱 | 구조화된 데이터 직접 읽기 |
| Excel (.xlsx) | openpyxl 파싱 | 엑셀 시트에서 데이터 추출 |
| PDF | PyPDF2 텍스트 추출 → 정규식 | PDF에서 텍스트 추출 후 파싱 |
| Word (.docx) | python-docx 텍스트 추출 → 정규식 | 문서에서 데이터 추출 |

**InBody 970 지원 필드 (전체):**

| 카테고리 | 항목 |
|---------|------|
| 기본 정보 | 키, 나이, 성별, 검사일, 모델명 |
| 체성분 분석 | 체수분, 세포내/외수분, 단백질, 무기질, 체지방, 체중, 근육량 |
| 골격근·지방 | 체중, 골격근량, 체지방량 |
| 비만 분석 | BMI, 체지방률 |
| 체중 조절 | 적정체중, 체중/지방/근육 조절량 |
| 연구항목 | 세포내/외수분, 기초대사량, 복부지방률, 체세포량, SMI |
| 내장지방 | VFA (내장지방단면적, cm²) |
| 부위별 근육 | 오른팔/왼팔/몸통/오른다리/왼다리 근육량 + 발달률(%) |
| 세포외수분비 | 전신 + 부위별 ECW 비율 |
| 신체변화 | 체중/골격근/체지방률 변화 히스토리 |

**교차 검증 (자동):**
- 체중 = 체수분 + 단백질 + 무기질 + 체지방 (구성 검증)
- BMI = 체중 / 키(m)² (역산 검증)
- 체지방률 = 체지방량 / 체중 × 100 (비율 검증)
- 골격근량 < 체중 (범위 검증)

**분석 결과에 포함되는 항목:**
- 체형 판정 (C자형/I자형/D자형)
- 비만 분석 (BMI + 체지방률 종합)
- 내장지방 위험도 (VFA 기준: 매우양호/양호/주의/위험)
- 근감소증 위험 (SMI 기준: AWGS 아시아 기준)
- 수분 균형 (ECW 비율)
- 부위별 근육 균형 (좌우 비대칭 감지)

**AI 코칭 메시지:**
- 🏆 잘하고 있어요 — 칭찬 포인트 목록
- 💡 이렇게 해보면 어떨까요 — 개선 제안
- 📋 추천 행동 — 구체적 행동 제안

**처리 흐름:**
```
파일 드래그앤드롭/클릭 → 파일 미리보기 표시
→ 모델 선택 (기본: gemma4:e4b)
→ POST /api/v1/inbody/upload (FormData 전송)
→ 파싱 → 교차 검증 → 종합 분석 → 코칭 메시지
→ 프로필에 자동 반영
```

### 2-3. AI와 대화하기 (챗봇)

**설명:** ChatGPT/클로드처럼 AI 코치와 대화하면서 자연스럽게 신체 정보를 입력하고 수정합니다.

**동작 방식:**
1. 사용자가 자연어로 메시지 입력 (예: "25살 남자, 178cm 82kg이야")
2. LLM이 응답 생성 + 프로필 데이터 추출 시도
3. NER(정규식 기반)로 나이/성별/키/체중/운동빈도 자동 추출
4. 추출된 데이터가 있으면 프로필에 자동 반영 ("📝 프로필에 반영됨" 표시)

**사용된 NLP 기법:**
- **LLM 대화:** Ollama exaone3.5:7.8b (한국어 최적화)
- **NER (개체명 인식):** 정규식 기반 — 숫자+단위 패턴 매칭
  - 나이: `(\d{1,2})\s*(?:세|살)` 또는 `(\d{2})대`
  - 성별: `(남성|여성|남자|여자)`
  - 키: `(?:키|신장)\s*(\d{2,3}\.?\d*)\s*(?:cm|센티)?`
  - 체중: `(?:몸무게|체중)\s*(\d{2,3}\.?\d*)\s*(?:kg|킬로)?`
  - 운동 빈도: `주\s*(\d)\s*(?:회|번)`

**대화 예시:**
```
사용자: "25살 남자 178cm 82kg이야. 살 좀 빼고 싶어"
AI 코치: "안녕하세요! 25세 남성, 178cm 82kg이시군요. BMI를 계산해보면 25.9로
         과체중 범위에 해당해요. 체지방 감소를 목표로 설정할게요!
         주 몇 회 운동 가능하세요?"
         📝 프로필 업데이트: age=25, gender=남성, height_cm=178, weight_kg=82
```

**API:** `POST /api/v1/chat`

### 2-4. 내 프로필 보기

**설명:** 지금까지 입력된 프로필 정보를 한눈에 확인합니다.

**표시 항목:**

| 섹션 | 항목 |
|------|------|
| 프로필 카드 | 아바타, 이름, 나이/성별, 운동 목표 |
| 신체 지표 | 키, 체중, BMI(비만도), 체지방률 |
| AI 건강 지표 | 기초대사량(BMR), 일일소모량(TDEE), 권장 섭취량 |
| 운동 정보 | 목표, 주당 횟수, 경험 수준, 제약사항 |
| 인바디 이력 | 최근 5회 측정 기록 (날짜, 점수) |

**API:** `GET /api/v1/profile/{user_id}`

## 3. 사용된 NLP 기법 및 모델 요약

| 기법 | 모델/방법 | 파일 | 성능 |
|------|---------|------|------|
| **NER (개체명 인식)** | 정규식 기반 규칙 | `profile_ner.py` | 정확도 **100%** (21/21) |
| **텍스트 분류 (목표)** | 키워드 매칭 (규칙) | `goal_classifier.py` | F1 **0.849** (85%) |
| **텍스트 분류 (목표)** | KcBERT 파인튜닝 (비교) | `goal_classifier_bert.py` | 학습 데이터 100개 준비 |
| **키워드 추출** | KeyBERT + multilingual-MiniLM | `keyword_extractor.py` | Top-5 키워드 |
| **비전 파싱** | Gemma 4 (Ollama) | `inbody_parser.py` | 교차검증 포함 |
| **BMR 계산** | Mifflin-St Jeor 공식 | `body_calculator.py` | ADA 권장 |
| **건강 위험도** | 규칙 기반 스크리닝 | `health_analyzer.py` | 내장지방/SMI/WHR |
| **텍스트 생성** | EXAONE 3.5 7.8B (Ollama) | `api/main.py` (chat) | 대화형 프로필 입력 |

```
src/profile/
├── profile_ner.py          # NER — 정규식 기반 엔티티 추출

├── user_history.py         # 사용자 측정 이력 관리 — JSON 파일 기반
└── evaluation.py           # 성능 평가 — NER 정확도, 분류 F1, BMR 비교

frontend/src/pages/
└── OnboardingPage.jsx      # React UI — 4탭 (폼/인바디/채팅/프로필)
```

## 6. 실험 결과

### NER 정확도
- **100%** (21개 필드 중 21개 정확)
- "30대" → 35세 변환, "센티/킬로" 비표준 단위 처리 성공

### 목표 분류 정확도
- **85%** (20개 테스트 중 17개 정확), Macro F1: **0.849**
- 체력향상 F1=1.00 (최고), 체중관리/건강개선 F1=0.75 (최저 — 키워드 중복)

### BMR 공식 비교
- Mifflin-St Jeor가 Harris-Benedict 대비 평균 **-91kcal** (과대추정 방지)
- 인바디 BMR이 있을 경우 인바디 값 우선 사용

## 7. 한계점 및 개선 방향

| 한계점 | 현재 | 개선 방향 |
|--------|------|---------|
| 목표 분류 정확도 | F1 0.849 | KcBERT 파인튜닝 (500개 학습 데이터) → F1 0.90+ |
| NER 범위 | 숫자+단위만 | LLM 기반 NER로 "살 빼고 싶어" 같은 간접 표현 추출 |
| 인바디 파싱 | 비전 모델 의존 (GPU) | OCR 경량화 폴백 강화 |
| 프로필 저장 | JSON 파일 | SQLite/PostgreSQL 전환 |
