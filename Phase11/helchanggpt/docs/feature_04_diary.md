# 기능 설명서: 운동 일기 (Stage 4 — 결(結))

> 운동 후 느낀 점을 기록하면 AI가 감정을 읽고, 선택한 캐릭터 스타일로 맞춤 피드백을 제공하는 기능

---

## 1. 기능 개요

"운동 일기"는 헬창지피티의 네 번째이자 마지막 단계로, 기승전결의 **결(結)** 에 해당합니다. 앞선 3단계(프로필→식단→운동)의 모든 데이터를 종합하여, 사용자에게 **"잘 하고 있다"는 확인과 다음 행동 방향**을 제공하는 마무리 역할을 합니다.

### 핵심 가치
- 운동 일지를 자연어로 작성하면 AI가 감성(긍정/부정/중립)을 자동 분석
- **5가지 캐릭터 모드** 중 선택하여 자신만의 스타일로 피드백을 받음
- 작성한 일기가 저장되어 성장 기록으로 축적
- 목표 달성률을 자동 추적하여 주별 진행 상황을 시각화

---

## 2. 페이지 구성 (3탭)

### 2-1. 오늘의 일기 탭

운동 일지를 작성하고, AI 피드백을 받는 메인 기능입니다.

**좌측 (3열): 일지 작성 + 감성 분석**

| 영역 | 기능 |
|------|------|
| 일지 입력 | 텍스트 에어리어 — 오늘 운동 느낀 점 자유 작성 |
| 첨부 기능 | 사진 첨부, 음성 메모 (UI 준비) |
| 분석 버튼 | "AI한테 피드백 받기" → 감성 분석 + 저장 + 피드백 생성 |
| 감성 원형 차트 | 긍정(😊)/부정(😮‍💨)/중립(😐) + 신뢰도 % |
| 집중도 차트 | 최고(🔥)/높음(💪)/보통(👌) + 몰입도 % |

**우측 (2열): 피드백 모드 선택 + AI 피드백**

| 영역 | 기능 |
|------|------|
| 모드 선택 | 5가지 캐릭터 중 택1 (아이콘 버튼) |
| AI 피드백 카드 | 선택한 캐릭터의 말투로 피드백 표시 |
| 칭찬 포인트 | 잘한 점 목록 |
| 개선 제안 | 이렇게 해보면? 목록 |
| 명언 | 캐릭터별 동기부여 한 마디 |

### 2-2. 성장 기록 탭

지금까지 작성한 모든 운동 일기를 시간순으로 볼 수 있습니다.

| 항목 | 설명 |
|------|------|
| 총 기록 수 | 작성한 일기 총 개수 (대형 숫자) |
| 일기 목록 | 날짜, 운동 시간, 수행 종목, 일지 내용 (최신순) |
| 운동 뱃지 | 수행한 운동 이름 (네온 뱃지) |

### 2-3. 목표 달성률 탭

설정한 운동 목표 대비 달성 현황을 분석합니다.

| 항목 | 설명 |
|------|------|
| 목표 메시지 | 달성률에 따른 응원 메시지 (🏆/💪/🌱/🔥) |
| 요약 카드 4개 | 총 운동 횟수, 총 운동 시간, 평균 달성률, 연속 운동일 |
| 주별 달성률 | 프로그레스 바로 최근 8주 표시 (목표 대비 색상 변화) |
| 연속 기록 | 현재 연속 운동일 + 최고 기록 |

**목표 달성 메시지 단계:**

| 평균 달성률 | 이모지 | 메시지 |
|----------|--------|--------|
| 90%+ | 🏆 | "대단해요! 목표를 꾸준히 달성하고 있어요!" |
| 60~89% | 💪 | "잘하고 있어요! 조금만 더 하면 완벽해요!" |
| 30~59% | 🌱 | "시작이 반이에요! 조금씩 늘려가 봐요!" |
| 0~29% | 🔥 | "지금 시작하면 돼요! 하나씩 채워가 봐요!" |

**연속 운동일 계산:**
- 2일 이내 간격이면 연속으로 인정 (예: 월-수-금 = 연속 3일)
- 마지막 운동이 2일 이내면 현재 스트릭 활성

| 힘들었을 때 | "운동 빈도가 계획 대비 67%였습니다. 수면 패턴과 영양 섭취를 점검해보시면 좋겠습니다." |

| 상황 | 예시 피드백 |

#### 🥊 매미킴

```
페르소나: UFC 파이터 김동현(스턴건) — 매미킴TV
톤: "운동 많이 된다" 긍정 마인드, 담담하지만 묘하게 웃기고 위로
```

| 상황 | 예시 피드백 |

## 4. 감성 분석 상세

### 분석 방식

**규칙 기반 (기본):** 키워드 매칭 + 강도 배율

**LLM 기반 (선택):** Ollama exaone3.5:7.8b에 프롬프트로 감성 분류

### 감정 키워드 사전

| 감성 | 감정 | 키워드 예시 |
|------|------|----------|
| **긍정** | 성취감 | 성공, 해냈, 올렸, 늘었, 달성, 신기록 |
| | 자신감 | 자신감, 뿌듯, 할 수 있, 대견, 잘 됐 |
| | 즐거움 | 재밌, 즐거, 같이, 함께, ㅋㅋ |
| | 만족감 | 만족, 충분, 개운, 상쾌, 오운완 |
| | 활력 | 에너지, 활력, 컨디션 좋, 기분 좋 |
| **부정** | 피로 | 피곤, 지쳤, 힘들, 녹초, 기운 없 |
| | 좌절 | 못 했, 실패, 포기, 안 됐, 자괴감 |
| | 통증 | 아프, 통증, 쑤시, 결림, 뻐근 |
| | 무기력 | 의욕 없, 귀찮, 하기 싫, 가기 싫 |
| | 스트레스 | 스트레스, 짜증, 답답, 못 지켰 |
| **중립** | 일상 | 그냥, 보통, 무난, 평범, 루틴대로 |

### 강도 배율

| 부사 | 배율 | 예시 |
|------|------|------|
| 너무, 엄청, 완전 | ×1.3 | "너무 피곤해서" → 부정 강화 |
| 정말, 진짜 | ×1.2 | "진짜 잘 됐다" → 긍정 강화 |
| 조금, 약간, 좀 | ×0.7~0.8 | "좀 힘들었다" → 부정 약화 |

### 실험 결과

| 메트릭 | 규칙 기반 |
|--------|---------|
| **감성 분류 정확도** | **70%** (7/10) |
| **세부 감정 정확도** | **60%** (6/10) |

**오분류 사례:**
- "체중이 2kg 줄었다! 식단 효과!" → 중립 (정답: 긍정) — "줄었다"가 긍정 키워드에 미포함
- "무릎이 좀 아팠다" → 중립 (정답: 부정) — "좀"이 강도를 낮춤
- "새 운동 배웠는데 신기했다" → 중립 (정답: 긍정) — "신기"가 키워드에 미포함

## 9. 한계점 및 개선 방향

| 한계점 | 현재 | 개선 방향 |
|--------|------|---------|
| 감성 분석 정확도 | 규칙 기반 70% | KcBERT 파인튜닝 (200개 학습 데이터) → 85%+ |
| 감정 세분류 | 키워드 미포함 시 미인식 | 키워드 사전 확장 + LLM 병행 |
| 운동 자동 감지 | 수동 입력만 | 텍스트에서 운동명 NER 자동 추출 |
| 변화 그래프 | 텍스트 목록만 | 체중/근육/체지방 변화 차트 시각화 |
| 사진 첨부 | UI만 준비 | 실제 이미지 업로드 + 운동 인증 |
| 음성 입력 | UI만 준비 | Whisper 등 STT 연동 |
| 알림 | 미구현 | 운동 리마인더 + 일기 작성 알림 |
