# 기능 설명서: 오늘 뭐 먹지? (Stage 2 — 승(承))

> AI 영양사와 대화하면서 나만의 맞춤형 식단을 생성하고, 알레르기/일정 변동에 대응하는 기능

---

## 1. 기능 개요

"오늘 뭐 먹지?"는 헬창지피티의 두 번째 단계로, Stage 1에서 입력한 프로필(나이, 키, 체중, 목표, 제약사항)을 기반으로 **AI가 맞춤형 3일치 식단을 생성**합니다. AI 영양사 챗봇과 대화하면서 식단을 만들고, 알레르기 음식을 제외하고, 회식 등 일정 변동에 대응할 수 있습니다.

### 핵심 가치
- 사용자의 목표(체지방 감소, 근력 증가 등)에 맞는 탄단지 비율을 자동 계산
- 알레르기/지병(당뇨, 고혈압 등)에 해당하는 음식을 자동 제외
- 3일치 식단을 한 번에 생성하며, 각 음식마다 대체 메뉴 2개를 제안
- 회식, 야근, 아침 건너뜀 등 갑작스러운 일정 변동에 자동 대응

---

## 2. 페이지 구성 (3탭)

### 2-1. AI 대화 탭

AI 영양사 챗봇과 대화하면서 식단을 생성하고 수정합니다.

**챗봇 기능:**

| 사용자 입력 | AI 동작 |
|-----------|--------|
| "식단 짜줘", "3일치 식단" | 프로필 기반 맞춤 식단 생성 |
| "점심 메뉴 바꿔줘" | 해당 끼니만 대체 메뉴 제안 |
| "닭가슴살 말고 다른 단백질로" | 특정 음식 교체 |
| "회식이야", "야근이야" | 일정 변동 감지 → 식단 자동 조정 |
| "견과류 알레르기가 있어" | 해당 식품 제외하고 재생성 |

**사이드 패널 기능:**

- **알레르기 토글 (10종):** 우유/유제품, 계란, 땅콩, 견과류, 밀/글루텐, 대두/콩, 갑각류, 생선, 조개류, 복숭아
- **추가 제외 식품 (6종):** 돼지고기, 소고기, 닭고기, 해산물, 유제품, 매운 음식
- **3일치 맞춤 식단 만들기 버튼:** 프로필+알레르기 기반 자동 생성
- **식단 사이드 미리보기 (v1.1 신규):** 생성 완료 시 3일치 식단을 사이드 패널에서 바로 확인 가능 — 날짜 탭 전환, 끼니별 메뉴·칼로리·음식 태그, 매크로(탄/단/지) 요약, "상세 보기"/"저장" 버튼

**처리 흐름:**
```
AI 대화 → POST /api/v1/diet/chat (LLM 응답 + 일정 변동 감지)
       → [MEAL_PLAN] 태그 감지 시 식단 자동 반영
       → "식단 보기" 탭으로 자동 전환

3일치 버튼 → POST /api/v1/diet/generate-multiday
           → 프로필 로드 + 탄단지 계산 + LLM 3일 식단 생성
           → 알레르기/제외 식품 반영
```

**끼니 카드 표시 항목:**
- 추천 시간 (네온 뱃지)

- 메뉴 이름
- 음식별: 이름, 양, 탄/단/지/칼로리
- 각 음식의 대체 메뉴 2개
- 식사 팁

### 2-3. 저장된 식단 탭 (v1.1 신규)

과거에 저장한 식단을 목록으로 확인하고, 불러오거나 삭제할 수 있습니다.

**표시 항목:**
- 식단 제목 (예: "3일치 맞춤 식단")
- 저장 일시
- 목표 칼로리, 일수
- 알레르기/제외 식품 수
- "불러오기" 버튼 → 해당 식단을 식단 보기 탭으로 로드
- "삭제" 버튼 → 이력에서 제거

**데이터 저장 경로:** `data/user_profiles/{user_id}/diet_history.json`

**페이지 진입 시 자동 복원:** 가장 최근 저장된 식단이 있으면 자동으로 로드하여, 페이지 새로고침 후에도 마지막 작업 식단을 바로 볼 수 있음.

## 3. 핵심 기능 상세

### 3-1. 탄단지 비율 자동 계산

사용자의 운동 목표에 따라 탄수화물:단백질:지방 비율을 자동 결정합니다.

| 목표 | 탄수화물 | 단백질 | 지방 | 설명 |
|------|---------|--------|------|------|
| **체지방감소** | 40% | 35% | 25% | 고단백·저탄수화물로 근손실 방지 |
| **근력증가** | 45% | 30% | 25% | 충분한 단백질 + 운동 에너지 |
| **체력향상** | 50% | 25% | 25% | 탄수화물 중심 에너지 확보 |
| **체중관리** | 50% | 25% | 25% | 균형 잡힌 영양소 비율 |
| **건강개선** | 45% | 25% | 30% | 복합 탄수화물 + 건강한 지방 |

**제약사항에 따른 비율 보정:**

| 제약사항 | 탄 조정 | 단 조정 | 지 조정 | 추가 규칙 |
|---------|--------|--------|--------|---------|
| 당뇨 | -10% | +5% | +5% | GI 지수 낮은 식품 권장 |
| 고혈압 | 0 | 0 | 0 | 나트륨 2000mg 이하 |
| 고지혈증 | 0 | 0 | -5% | 포화지방 줄이기 |
| 신장질환 | +5% | -10% | +5% | 단백질 제한, 칼륨 주의 |

**체중 기반 최소 단백질 보장:** 체중 × 1.2g 이상

### 3-2. 알레르기/제외 식품 처리

**알레르기 10종:**
우유/유제품, 계란, 땅콩, 견과류, 밀/글루텐, 대두/콩, 갑각류, 생선, 조개류, 복숭아

**추가 제외 6종:**
돼지고기, 소고기, 닭고기, 해산물, 유제품, 매운 음식

**처리 방식:**
- LLM 프롬프트에 `[제외 식품 — 절대 포함 금지]` 섹션으로 전달
- 대체 음식에도 제외 식품 미포함
- 생성 후 `diet_analyzer.py`에서 제약사항 위반 재검증
- 위반 시 경고 메시지 표시

### 3-3. 일정 변동 자동 대응

사용자가 챗봇에 일정 변경을 알리면 **6가지 시나리오를 자동 감지**합니다.

| 시나리오 | 감지 키워드 | 자동 대응 |
|---------|----------|---------|
| **야근/늦은 저녁** | "야근", "늦게 먹", "저녁 늦" | 저녁 칼로리 30% 감소 + 점심 보강 + 소화 부담 적은 메뉴 |
| **아침 건너뜀** | "못 먹", "건너뛰", "안 먹" | 나머지 끼니에 칼로리 재배분 + 단백질 보충 간식 |
| **회식/외식** | "회식", "외식", "약속" | 회식 칼로리 추정(800kcal) + 다른 끼니 절약 |
| **운동 안 하는 날** | "운동 안", "쉬는 날" | 운동 전후 간식 제거 + 총 칼로리 100~200kcal 감소 |
| **메뉴 교체** | "바꿔", "다른 거", "변경" | 동일 칼로리 범위 대체 메뉴 3개 제안 |
| **추가 음식 섭취** | "치킨 먹었", "피자 먹었" | 추가 칼로리 추정 + 다음날 보정 제안 |

### 3-4. 외식 칼로리 추정 DB

21개 외식/회식 메뉴의 추정 칼로리와 팁을 제공합니다.

| 메뉴 | 추정 칼로리 | 팁 |
|------|----------|-----|
| 회식(일반) | 800kcal | 채소 반찬 먼저, 국물 나트륨 주의 |
| 회식(고기) | 1,000kcal | 살코기 위주, 쌈채소 많이 |
| 치킨 | 700kcal | 반마리 기준, 순살보다 뼈닭이 낮음 |
| 피자 | 600kcal | 2~3조각, 씬크러스트 선택 |
| 라면 | 500kcal | 국물 절반만, 나트륨 1800mg+ |
| 삼겹살 | 600kcal | 200g 기준, 목살이 덜 기름 |
| 초밥 | 450kcal | 10개 기준, 간장 적게 |
| 카페라떼 | 200kcal | 톨사이즈, 시럽 빼기 |
| ... | ... | (총 21종) |

### 3-5. 3일치 식단 + 대체 음식

**3일치 생성:**
- 매일 아침/점심/저녁/간식 4끼 × 3일 = 12끼
- 날짜별 탭 전환 (1일차/2일차/3일차)
- 하루마다 다른 메뉴 구성

**대체 음식:**
- 각 음식마다 대체 메뉴 2개 제안
- 제외 식품은 대체 음식에도 미포함
- 예: 닭가슴살 → 대체: 두부, 연어

### 3-6. 영양소 검증 + 분석

생성된 식단을 자동으로 분석합니다.

| 검증 항목 | 방법 |
|---------|------|
| 칼로리 정확도 | 목표 대비 오차 (%) |
| 탄단지 비율 오차 | 목표 비율 대비 실제 비율 차이 |
| 제약사항 위반 | 당뇨→1끼 탄수화물 50g 초과, 고혈압→나트륨 2000mg 초과 |
| 음식별 교차 검증 | 식품안전나라 API(1,146건) DB와 칼로리 대조 |
| 종합 점수 | 0~100점 + A/B/C/D 등급 |

## 4. 사용된 NLP 기법 및 모델

| 기법 | 모델/방법 | 파일 | 용도 |
|------|---------|------|------|
| **텍스트 생성 (식단)** | EXAONE 3.5 7.8B (Ollama) | `diet_generator.py` | 맞춤 식단 생성 |
| **프롬프트 엔지니어링** | Zero-shot / Few-shot / CoT / Scheduled | `diet_prompts.py` | 4가지 프롬프트 비교 |
| **키워드 추출** | KeyBERT | `diet_analyzer.py` | 영양 키워드 추출 |
| **텍스트 분류 (일정)** | 규칙 기반 (키워드 매칭) | `diet_adjuster.py` | 6가지 일정 변동 감지 |
| **정보 검색** | 식품안전나라 API + 로컬 DB | `nutrition_db.py` | 영양소 교차 검증 |
| **수치 계산** | 탄단지 비율 공식 | `macro_calculator.py` | ACSM/ISSN 기준 |

### 프롬프트 방식 비교

| 방식 | 특성 | JSON 준수율 | 권장 상황 |
|------|------|-----------|---------|
| **Zero-shot** | 지시만으로 생성, 간결 | 높음 | 빠른 단순 식단 |
| **Few-shot** (기본) | 예시 기반, 품질 안정 | 매우 높음 | **일반 식단 생성** |
| **CoT** | 단계별 추론, 영양소 정확 | 중간 | 제약사항 복잡한 경우 |
| **Scheduled** | 시간대+운동 연동 | 높음 | 운동 전후 간식 포함 |

### temperature 튜닝

| temperature | 다양성 | 정확도 | 용도 |
|------------|--------|--------|------|
| 0.3 | 낮음 | 높음 | 인바디 수치 파싱 |
| **0.7** (기본) | 균형 | 균형 | **일반 식단 생성** |
| 1.0 | 높음 | 낮음 | 다양한 메뉴 탐색 |
