### 2.1 사용 데이터

### 2.2 사용 변수

| 변수명        | 설명                     | 출처          |
| ------------- | ------------------------ | ------------- |
| `Pearson_r`   | Pearson 상관계수         | 상관분석 결과 |
| `Pearson_sig` | 통계적 유의성 (p < 0.05) | 상관분석 결과 |
| `Slope`       | 회귀계수 (기울기)        | 회귀분석 결과 |
| `R_squared`   | 결정계수 (설명력)        | 회귀분석 결과 |

### 2.3 결론 도출 방법

#### 상관계수 해석 기준

| 상관계수 범위 | 강도 해석 |
| ------------- | --------- | ----- | --------- |
|               | r         | > 0.7 | 강한 상관 |
| 0.3 <         | r         | ≤ 0.7 | 중간 상관 |
|               | r         | ≤ 0.3 | 약한 상관 |

#### 통계적 유의성 기준

| p-value   | 유의성               |
| --------- | -------------------- |
| p < 0.001 | 매우 유의함 (\*\*\*) |
| p < 0.01  | 유의함 (\*\*)        |
| p < 0.05  | 유의함 (\*)          |
| p ≥ 0.05  | 유의하지 않음 (ns)   |

```
[상관분석 결과]

   - potatoes: r = 0.559 (중간 양의 상관, 유의함)

```

### 2.5 핵심 인사이트

> **모든 햄버거 재료에서 기온과 생산량 사이에 통계적으로 유의미한 양의 상관관계가 존재한다.**
>
> 단, 해석 시 주의사항:
>
> 1. **상관관계 ≠ 인과관계:** 기온 상승이 생산량 증가를 "야기"한다고 단정할 수 없음
> 2. **교란변수 존재:** 농업 기술 발전, 재배 면적 확대, 비료/관개 기술 개선 등이 혼재
> 3. **시계열 경향성:** 두 변수 모두 시간에 따라 상승하는 경향이 있어 허위 상관 가능성

## 3. 핵심 발견사항 2: 기후 영향의 시차 효과

### 3.1 사용 데이터

| 항목          | 내용                          |
| ------------- | ----------------------------- |
| **데이터셋**  | `stat_02_lag_correlation.csv` |
| **분석 기간** | 2000년 ~ 2019년               |
| **시차 범위** | 0~5년                         |

### 3.2 사용 변수

| 변수명        | 설명                     | 단위    |
| ------------- | ------------------------ | ------- |
| `Item`        | 품목명                   | -       |
| `Lag_Years`   | 시차 연도                | 년      |
| `Correlation` | 해당 시차에서의 상관계수 | -       |
| `Significant` | 통계적 유의성            | Boolean |

### 3.3 결론 도출 방법

#### 최적 시차 선정 기준

- 각 품목에 대해 상관계수의 절대값이 최대인 시차(lag)를 최적 시차로 선정
- 유의성(p < 0.05) 충족 여부 확인

```python
# 최적 시차 계산
for item in df['Item'].unique():
    df_item = df[df['Item'] == item]
    best_idx = df_item['Correlation'].abs().idxmax()
    best_row = df_item.loc[best_idx]
    optimal_lag = int(best_row['Lag_Years'])
```

| tomatoes | 0년       | 0.762    | 즉각적 반응    |

### 3.5 핵심 인사이트

> **기후 영향은 대부분 즉각적이나, 일부 품목(특히 축산물)에서 1-2년 지연 효과가 관찰된다.**
>
> 시사점:
>
> - 올해의 기후 이상이 내년/내후년 식품 가격에 영향 가능

```

회복률 = (이듬해 생산량 - 이벤트 연도 생산량) / 이벤트 연도 생산량 × 100
```

## 6. 통계적 가설 검정 결과

### 6.1 가설 검정 개요

| 가설   | H₀ (귀무가설)                  | H₁ (대립가설)    | 검정 방법        |
| ------ | ------------------------------ | ---------------- | ---------------- |
| 가설 1 | 기온 변화와 생산량 간 상관없음 | 상관관계 존재    | Pearson 상관분석 |
| 가설 2 | 이상기후 전후 생산량 차이 없음 | 이상기후 시 감소 | 이벤트 스터디    |
| 가설 3 | 기간별 변동성 차이 없음        | 최근 변동성 증가 | 변동성 분석      |

### 6.2 가설별 검정 결과

#### 가설 1: 기온-생산량 상관관계

```
H₀: 기온 변화와 생산량 사이에 상관관계가 없다
H₁: 기온 변화와 생산량 사이에 상관관계가 있다
검정: Pearson 상관분석
결과: 기각 (6/6 품목에서 p < 0.05)
결론: 통계적으로 유의미한 상관관계 존재
```

#### 가설 2: 이상기후 영향

```
H₀: 이상기후 발생 전후 생산량에 차이가 없다
H₁: 이상기후 발생 시 생산량이 감소한다
검정: 이벤트 스터디
결과: 부분적 기각 (일부 이벤트에서 유의미한 감소)
결론: 이상기후는 생산량에 부정적 영향
```

#### 가설 3: 변동성 변화

```
H₀: 기간별 생산량 변동성에 차이가 없다
H₁: 최근 기간의 생산량 변동성이 더 크다
검정: 변동성 분석 (표준편차 비교)
결과: 부분적 기각
결론: 일부 품목에서 변동성 증가 경향
```

### 6.3 결론

> **세 가지 가설 검정 모두에서 기후 변화가 농업 생산에 영향을 미친다는 증거가 발견되었다.**
>
> - 기온-생산량 상관관계: 명확히 존재
> - 이상기후 영향: 단기적 충격 확인
> - 변동성 증가: 일부 품목에서 경향성 관찰
