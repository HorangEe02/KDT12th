# 02. 데이터 시각화 상세 설명

## 개요

본 문서는 `02_data_visualization.py`에서 생성된 9개의 시각화에 대해 다음 내용을 상세히 설명합니다:

- 사용된 데이터셋 및 변수
- 시각화 선택 이유
- 분석 결과 및 결론

**데이터 출처:**

- FAOSTAT (https://www.fao.org/faostat/en/#data)
- Kaggle Climate Change Impact on Agriculture (https://www.kaggle.com/datasets/waqi786/climate-change-impact-on-agriculture)

## Figure 1. 글로벌 기온 변화 추이 (viz_01_temperature_trend.png)

![글로벌 기온 변화 추이](../output/figures/viz_01_temperature_trend.png)

### 1.1 사용 데이터셋

| 항목          | 내용                                           |
| ------------- | ---------------------------------------------- |
| **데이터셋**  | `temperature_processed.csv`                    |
| **원본 출처** | FAOSTAT Temperature Change (NASA GISTEMP 기반) |
| **기간**      | 1990년 ~ 2019년                                |

### 1.2 사용 변수

| 변수명         | 설명                            | 단위 |
| -------------- | ------------------------------- | ---- |
| `Year`         | 연도                            | 년   |
| `Area`         | 지역/국가 (필터: 'World')       | -    |
| `Temp_Anomaly` | 기온 편차 (1951-1980 기준 대비) | °C   |

### 1.3 시각화 선택 이유

- **막대 그래프 (Bar Chart)**: 연도별 기온 편차를 직관적으로 비교 가능
- **색상 그라디언트**: 기온 상승 정도를 시각적으로 강조 (파란색→주황색→빨간색)
- **추세선 (2차 다항식)**: 비선형적 온난화 추세를 포착
- **1.5°C 목표선**: 파리협정 목표 대비 현재 위치 파악

### 1.4 결과

```
- 1990년: 0.636°C
- 2019년: 1.473°C
- 변화량: +0.837°C (약 30년간)
```

### 1.5 결론

> **글로벌 기온은 1990년 이후 꾸준히 상승하여 파리협정 1.5°C 목표에 근접하고 있다.**
> 특히 2015년 이후 상승 속도가 가속화되는 추세를 보인다.

| **원본 출처** | FAOSTAT Crops and Livestock Products                                                                                                                      |
| **기간**      | 2000년 ~ 2023년                                                                                                                                           |

### 3.2 사용 변수

| 변수명        | 설명              | 단위        |
| ------------- | ----------------- | ----------- |
| `Year`        | 연도              | 년          |

### 3.3 분석 대상 품목

| 품목              | 햄버거 구성요소 | 색상             |
| ----------------- | --------------- | ---------------- |
| Wheat (밀)        | 빵/번           | 노란색 (#F1C40F) |
| Beef (소고기)     | 패티            | 빨간색 (#E74C3C) |
| Tomatoes (토마토) | 케첩            | 주황색 (#E67E22) |

| Potatoes (감자)   | 감자튀김        | 보라색 (#9B59B6) |
| Cucumbers (오이)  | 피클            | 청록색 (#1ABC9C) |

### 3.4 시각화 선택 이유

- **영역 그래프 (Area Chart)**: 생산량의 누적적 성장을 강조
- **6개 서브플롯**: 품목 간 스케일 차이로 인해 개별 비교 필요
- **변화율 표시**: 2000년 대비 2023년 변화를 퍼센트로 명시

### 3.5 결과

```
품목별 생산량 변화 (2000→2023):
- Wheat: +47.8%
- Beef: +23.7%
- Tomatoes: +67.3%
- Lettuce: +58.9%
- Potatoes: +32.4%
- Cucumbers: +94.2%
```

### 3.6 결론

> **모든 햄버거 재료의 글로벌 생산량이 2000년 이후 증가 추세를 보인다.**
> 이는 농업 기술 발전, 재배 면적 확대, 수요 증가를 반영한다. 단, 이 증가 추세가 기후 변화의 부정적 영향이 없음을 의미하지는 않는다.

| 항목          | 내용                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| **데이터셋**  | `wheat_production.csv`, `tomatoes_production.csv`, `potatoes_production.csv`, `lettuce_production.csv` |
| **원본 출처** | FAOSTAT                                                                                                |
| **기간**      | 2000년 ~ 2019년 (기온 데이터 가용 기간)                                                                |

### 4.2 사용 변수

| 변수명         | 설명              | 단위    | 축         |
| -------------- | ----------------- | ------- | ---------- |
| `Year`         | 연도              | 년      | X축        |
| `World_Total`  | 전 세계 총 생산량 | 백만 톤 | 왼쪽 Y축   |
| `Temp_Anomaly` | 기온 편차         | °C      | 오른쪽 Y축 |

### 4.3 시각화 선택 이유

- **이중 Y축 (Dual Y-axis)**: 스케일이 다른 두 변수를 동시에 비교
- **영역 채우기 + 점선**: 생산량(실선)과 기온(점선)을 시각적으로 구분
- **4개 주요 품목 선정**: 햄버거 핵심 재료에 집중

### 4.4 결과

```
품목별 기온-생산량 동시 추세:
- Wheat: 기온 상승과 함께 생산량 증가
- Tomatoes: 유사한 패턴
- Potatoes: 완만한 증가
- Lettuce: 기온과 높은 동조화
```

### 4.5 결론

> **기온 상승과 생산량 증가가 동시에 나타나는 패턴이 관찰된다.**
> 그러나 이는 인과관계가 아닌 상관관계이며, 기술 발전이라는 교란변수가 존재한다. 상관분석을 통한 정량적 검증이 필요하다.

### 6.2 사용 변수

| 변수명                  | 설명      | 단위      |
| ----------------------- | --------- | --------- |
| `Average_Temperature_C` | 평균 기온 | °C        |

United States, China, India, Brazil, Australia, Canada, France, Germany, Argentina, Russia

### 6.4 시각화 선택 이유

- **산점도 (Scatter Plot)**: 두 연속 변수 간의 관계 패턴 탐색
- **2차 다항 추세선**: 비선형 관계 포착 (기온과 수율의 역U자 관계)
- **국가별 색상 구분**: 지역적 차이 시각화

```
추세선 방정식: y = -0.0025x² + 0.0980x + 1.6374
최적 온도: 약 19.6°C
```

### 6.6 결론

> **기온과 작물 수율 사이에 비선형(역U자형) 관계가 존재한다.**
> 일정 온도까지는 수율이 증가하지만, 최적 온도를 넘어서면 수율이 감소한다. 이는 기후 변화가 농업 생산성에 부정적 영향을 미칠 수 있음을 시사한다.

## Figure 8. 종합 대시보드 (viz_08_summary_dashboard.png)

![종합 대시보드](../output/figures/viz_08_summary_dashboard.png)

### 8.1 사용 데이터셋

| 섹션 | 데이터셋                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------- |
| 1행  | `temperature_processed.csv`                                                                         |
| 2행  | `wheat_production.csv`, `tomatoes_production.csv`, `potatoes_production.csv`, `beef_production.csv` |
| 3행  | `kaggle_climate_agriculture.csv`                                                                    |

### 8.2 사용 변수

| 섹션   | 변수                                                    |
| ------ | ------------------------------------------------------- |
| 기온   | `Year`, `Area`, `Temp_Anomaly`                          |
| 생산량 | `Year`, `World_Total`                                   |
| Kaggle | `Year`, `Average_Temperature_C`, `Crop_Yield_MT_per_HA` |

### 8.3 시각화 선택 이유

- **대시보드 형식**: 프로젝트 핵심 메시지를 한눈에 전달
- **3행 구성**: 기온 → 생산량 → 수율의 인과 흐름 시각화
- **일관된 색상 체계**: 재료별 고유 색상 유지

### 8.4 결과

대시보드는 다음을 종합적으로 보여줌:

1. 글로벌 기온의 지속적 상승
2. 햄버거 재료(밀, 토마토, 감자, 소고기) 생산량 증가
3. 기온과 수율의 관계

### 8.5 결론

> **"기후변화는 먼 미래가 아니라, 오늘 점심 메뉴에 영향을 미치는 현실이다."**
> 대시보드는 기후 변화 → 농업 생산 → 식품 소비로 이어지는 연결고리를 시각적으로 증명한다.

- **히트맵 (Heatmap)**: 다변량 상관관계를 한눈에 파악
- **RdBu 색상맵**: 양의 상관(빨강)과 음의 상관(파랑) 직관적 구분
- **하삼각행렬**: 중복 제거로 가독성 향상
- **상관계수 값 표시**: 정량적 해석 가능

### 9.4 결과

```
기온(Temp_Anomaly)과의 상관계수:
- cucumbers: 0.77
- lettuce: 0.77
- tomatoes: 0.76
- wheat: 0.73
- beef: 0.72
- potatoes: 0.56
```

### 9.5 결론

> **모든 햄버거 재료의 생산량이 기온 편차와 높은 양의 상관관계를 보인다 (r > 0.5).**
> 이는 기온 상승과 생산량 증가가 동시에 발생하고 있음을 의미하나, 인과관계를 증명하지는 않는다. 기술 발전이라는 교란변수를 통제한 추가 분석이 필요하다.
