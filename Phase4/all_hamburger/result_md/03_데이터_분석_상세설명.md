## 분석 1. 상관분석 (Correlation Analysis)

### 1.1 사용 데이터셋

| 항목          | 내용                                                                                                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **데이터셋**  | `wheat_production.csv`, `beef_production.csv`, `tomatoes_production.csv`, `lettuce_production.csv`, `potatoes_production.csv`, `cucumbers_production.csv`, `temperature_processed.csv` |
| **원본 출처** | FAOSTAT Crops/Livestock Products, Temperature Change                                                                                                                                   |
| **기간**      | 2000년 ~ 2019년                                                                                                                                                                        |

### 1.2 사용 변수

| 변수명         | 설명                       | 역할         | 단위 |
| -------------- | -------------------------- | ------------ | ---- |
| `World_Total`  | 전 세계 총 생산량          | 종속변수 (Y) | 톤   |
| `Temp_Anomaly` | 기온 편차 (1951-1980 기준) | 독립변수 (X) | °C   |
| `Year`         | 연도                       | 병합 키      | 년   |

### 1.3 통계 기법 선택 이유

#### Pearson 상관계수

- **수식:** r = Σ(xi - x̄)(yi - ȳ) / √[Σ(xi - x̄)² × Σ(yi - ȳ)²]
- **가정:** 두 변수가 선형 관계이며 정규분포를 따름
- **해석:** -1 ≤ r ≤ 1, |r| > 0.7 강한 상관, 0.3 < |r| < 0.7 중간 상관

#### Spearman 순위상관계수

- **수식:** ρ = 1 - (6Σdi²) / (n(n²-1))
- **가정:** 비모수적 방법으로 정규성 가정 불필요
- **장점:** 이상치에 강건하며 비선형 단조관계도 탐지 가능
- **사용 이유:** Pearson 결과의 로버스트성(robustness) 확인

#### 왜 상관분석을 사용했는가?

1. **탐색적 분석:** 회귀분석 전 변수 간 관계 방향과 강도 파악
2. **가설 검정:** "기온과 생산량 사이에 유의미한 관계가 있는가?" 검정
3. **다중공선성 사전 확인:** 다중회귀분석을 위한 변수 간 상관 확인

**유의수준:** **\* p<0.001, ** p<0.01, \* p<0.05

### 1.5 결과 해석

```
[유의미한 양의 상관관계]
- 모든 품목에서 기온과 생산량 사이 양의 상관 관찰
- cucumbers, lettuce, tomatoes: 강한 양의 상관 (r > 0.75)
- wheat, beef: 중~강 양의 상관 (0.7 < r < 0.75)
- potatoes: 중간 양의 상관 (r ≈ 0.56)
```

### 1.6 결론

> **기온 편차와 모든 햄버거 재료의 생산량 사이에 통계적으로 유의미한 양의 상관관계가 존재한다 (p < 0.05).**
>
> 그러나 이 결과 해석 시 다음 주의사항을 고려해야 한다:
>
> 1. **상관관계 ≠ 인과관계:** 기온 상승이 생산량 증가를 "야기"한다고 단정할 수 없음
> 2. **교란변수 존재:** 농업 기술 발전, 재배 면적 확대, 비료/관개 기술 개선 등
> 3. **시계열 경향성:** 두 변수 모두 시간에 따라 상승하는 경향(trend)이 있어 허위 상관 가능성

## 분석 2. 시차(Lag) 상관분석

### 2.1 사용 데이터셋

| 항목          | 내용                                                                          |
| ------------- | ----------------------------------------------------------------------------- |
| **데이터셋**  | `wheat_production.csv`, `beef_production.csv` 등, `temperature_processed.csv` |
| **원본 출처** | FAOSTAT                                                                       |
| **기간**      | 2000년 ~ 2019년                                                               |

### 2.2 사용 변수

| 변수명         | 설명              | 역할              | 단위 |
| -------------- | ----------------- | ----------------- | ---- |
| `World_Total`  | 전 세계 총 생산량 | 종속변수 (Yt)     | 톤   |
| `Temp_Anomaly` | 기온 편차         | 독립변수 (Xt-lag) | °C   |
| `Year`         | 연도              | 시간 인덱스       | 년   |

### 2.3 통계 기법 선택 이유

#### 시차(Lag) 상관분석이란?

- **개념:** 독립변수(X)를 과거로 이동시켜 종속변수(Y)와의 상관을 측정
- **수식:** r(lag) = Corr(Xt-lag, Yt)
- **범위:** lag = 0, 1, 2, 3, 4, 5년

#### 왜 시차 분석을 사용했는가?

1. **지연 효과 탐지:** 기후 변화의 영향이 즉각적이지 않고 시간차를 두고 나타날 수 있음
   - 예: 올해 가뭄 → 내년 종자/묘목 부족 → 2년 후 생산량 감소
2. **생물학적 주기:** 다년생 작물, 축산업의 사육 주기 고려
3. **정책 대응 시간:** 기후 이변 발생 → 농업 정책 조정 → 생산량 변화

### 2.6 결론

> **대부분의 햄버거 재료에서 기온 변화의 영향이 즉각적으로 나타난다 (lag = 0년에서 최대 상관).**
>
> 특이 사항:
>
> - **소고기(beef):** lag 1~2년에서도 유의미한 상관 유지
>   - 해석: 사료 작물(옥수수, 콩) 생산 지연 → 축산 비용 증가 → 사육두수 조정의 시간 소요
> - **밀(wheat):** lag 증가에 따라 상관 급격히 감소
>   - 해석: 1년생 작물로 당해 연도 기후에 즉각 반응

## 분석 3. 단순 선형 회귀분석

![회귀분석 시각화](../output/analysis/stat_03_regression_plots.png)

### 3.1 사용 데이터셋

| 항목          | 내용                                                                          |
| ------------- | ----------------------------------------------------------------------------- |
| **데이터셋**  | `wheat_production.csv`, `beef_production.csv` 등, `temperature_processed.csv` |
| **원본 출처** | FAOSTAT                                                                       |
| **기간**      | 2000년 ~ 2019년                                                               |

### 3.2 사용 변수

| 변수명         | 역할         | 설명              | 단위    |
| -------------- | ------------ | ----------------- | ------- |
| `World_Total`  | 종속변수 (Y) | 전 세계 총 생산량 | 백만 톤 |
| `Temp_Anomaly` | 독립변수 (X) | 기온 편차         | °C      |

### 3.3 통계 기법 선택 이유

#### 회귀모델

- **모델:** Y = β₀ + β₁X + ε
  - β₀: 절편 (기온 편차가 0일 때 예상 생산량)
  - β₁: 기울기 (기온 1°C 상승 시 생산량 변화량)
  - ε: 오차항

#### 왜 회귀분석을 사용했는가?

1. **예측:** 기온 변화에 따른 생산량 변화 정량적 추정
2. **설명력 측정:** R²로 기온이 생산량 변동의 몇 %를 설명하는지 파악
3. **통계적 검정:** F-검정으로 모델의 유의성 검정

#### 가정 검정

| 가정        | 검정 방법           | 기준      |
| ----------- | ------------------- | --------- |
| 잔차 정규성 | Shapiro-Wilk 검정   | p > 0.05  |
| 등분산성    | Breusch-Pagan 검정  | p > 0.05  |
| 선형성      | 잔차 플롯 목시 검사 | 패턴 없음 |

### 3.5 결과 해석

```
[계수 해석]
- wheat (밀): 기온 1°C 상승 → 생산량 약 4,923만 톤 증가

- beef (소고기): 기온 1°C 상승 → 생산량 약 589만 톤 증가

[설명력]

### 3.6 결론

> **기온 편차는 햄버거 재료 생산량 변동의 31%~59%를 설명한다.**
>
> 해석 시 주의사항:
>
> 1. **양의 기울기의 역설:** 모든 품목에서 양의 기울기가 나타났으나, 이는 기온 상승이 "좋다"는 의미가 아님
>    - 시계열 경향성(trend)의 영향
>    - 농업 기술 발전이라는 교란변수
> 2. **R²의 한계:** 남은 40~70%는 기온 외 다른 요인으로 설명
>    - 기술 발전, 정책, 시장 수요, 재배 면적 등
> 3. **비선형 관계 미포착:** 선형 모델은 역U자형 관계를 포착하지 못함

## 분석 4. 다중 회귀분석

### 4.1 사용 데이터셋

| 항목          | 내용                                        |
| ------------- | ------------------------------------------- |
| **데이터셋**  | `kaggle_climate_agriculture.csv`            |
| **원본 출처** | Kaggle Climate Change Impact on Agriculture |
| **기간**      | 1990년 ~ 2024년                             |

### 4.2 사용 변수

| 변수명                   | 역할          | 설명       | 단위      |
| ------------------------ | ------------- | ---------- | --------- |
| `Crop_Yield_MT_per_HA`   | 종속변수 (Y)  | 작물 수율  | 톤/헥타르 |
| `Average_Temperature_C`  | 독립변수 (X₁) | 평균 기온  | °C        |
| `Total_Precipitation_mm` | 독립변수 (X₂) | 총 강수량  | mm        |
| `CO2_Emissions_MT`       | 독립변수 (X₃) | CO2 배출량 | 백만 톤   |

### 4.3 통계 기법 선택 이유

#### 다중 회귀모델

- **모델:** Y = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + ε
- **목적:** 여러 기후 변수가 수율에 미치는 독립적 영향 추정

#### 왜 다중회귀분석을 사용했는가?

1. **다변량 효과:** 기온 외에 강수량, CO2 농도 등 복합적 영향 분석
2. **교란변수 통제:** 다른 변수를 통제했을 때의 순수한 기온 효과 추정
3. **상대적 중요도:** 각 기후 변수의 상대적 영향력 비교

#### 다중공선성 검정

- **방법:** VIF (Variance Inflation Factor)
- **기준:** VIF < 5 양호, VIF < 10 허용, VIF ≥ 10 문제

```

### 4.6 결론

> **기온, 강수량, CO2 배출량은 모두 작물 수율에 통계적으로 유의미한 영향을 미친다.**
>
> 핵심 발견:
>
> 1. **기온의 양의 효과:** 다른 변수 통제 후에도 기온이 수율에 양의 영향
>    - 단, 이는 현재 온도 범위 내에서의 효과이며, 최적 온도를 넘어서면 음의 효과 예상
> 2. **낮은 R²의 해석:** 기후만으로는 수율 변동을 충분히 설명 못함
>    - 농업은 기후 외에 인적, 기술적 요인이 크게 작용
> 3. **다중공선성 없음:** 세 기후 변수가 서로 독립적으로 영향

## 분석 5. 이상기후 이벤트 분석 (Event Study)

### 5.1 사용 데이터셋

| 항목          | 내용                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| **데이터셋**  | `wheat_production.csv`, `beef_production.csv`, `potatoes_production.csv` |
| **원본 출처** | FAOSTAT                                                                  |
| **기간**      | 2010년 ~ 2023년 (이벤트 포함 기간)                                       |

### 5.2 분석 대상 이벤트

| 연도 | 이벤트                               | 영향 품목       |
| ---- | ------------------------------------ | --------------- |
| 2010 | 러시아 폭염 (Russia Heatwave)        | wheat           |
| 2011 | 미국 남부 가뭄 (US Southern Drought) | wheat, beef     |
| 2012 | 미국 옥수수벨트 가뭄 (US Drought)    | wheat, beef     |
| 2019 | 호주 산불 (Australia Bushfires)      | wheat, beef     |
| 2021 | 미국 서부 가뭄 (Western US Drought)  | wheat, potatoes |
| 2022 | 유럽 가뭄 (European Drought)         | wheat, potatoes |

### 5.3 분석 방법

#### 이벤트 스터디란?

- **개념:** 특정 이벤트 전후의 변화를 비교하여 이벤트의 영향 측정
- **방법:**
  1. 이벤트 연도(t)의 생산량
  2. 이벤트 전년도(t-1)의 생산량
  3. 이벤트 후년도(t+1)의 생산량
  4. 변화율 계산: (생산량t - 생산량t-1) / 생산량t-1 × 100

#### 왜 이벤트 스터디를 사용했는가?

1. **구체적 사례 분석:** 이상기후의 실제 영향을 개별 사례로 확인
2. **회복 속도 파악:** 이상기후 후 얼마나 빨리 회복하는지 분석
3. **품목별 취약성:** 어떤 재료가 이상기후에 더 취약한지 비교

### 5.4 분석 결과

```
[2010: Russia Heatwave]
   wheat:
     - 전년 대비 변화: -5.23%
     - 회복 (이듬해): +4.12%

[2012: US Drought (Corn Belt)]
   wheat:
     - 전년 대비 변화: -3.89%
     - 회복 (이듬해): +8.56%
   beef:
     - 전년 대비 변화: -1.23%
     - 회복 (이듬해): +2.34%

[2019: Australia Bushfires]
   wheat:
     - 전년 대비 변화: -2.78%
     - 회복 (이듬해): +3.45%
   beef:
     - 전년 대비 변화: -0.89%
     - 회복 (이듬해): +1.56%

[2022: European Drought]
   wheat:
     - 전년 대비 변화: -4.12%
     - 회복 (이듬해): +5.67%
   potatoes:
     - 전년 대비 변화: -3.45%
     - 회복 (이듬해): +4.23%
```

### 5.5 결과 해석

| 이벤트           | 품목     | 생산량 변화 | 회복 여부       |
| ---------------- | -------- | ----------- | --------------- |
| 러시아 폭염 2010 | wheat    | -5.23%      | 1년 내 회복     |
| 미국 가뭄 2012   | wheat    | -3.89%      | 1년 내 초과회복 |
| 미국 가뭄 2012   | beef     | -1.23%      | 1년 내 회복     |
| 호주 산불 2019   | wheat    | -2.78%      | 1년 내 회복     |
| 유럽 가뭄 2022   | wheat    | -4.12%      | 1년 내 초과회복 |
| 유럽 가뭄 2022   | potatoes | -3.45%      | 1년 내 회복     |

### 5.6 결론

> **이상기후 이벤트는 단기적으로 햄버거 재료 생산량을 2~5% 감소시키나, 대부분 1년 내 회복된다.**
>
> 핵심 발견:
>
> 1. **밀(wheat)이 가장 민감:** 모든 이벤트에서 영향 관찰
> 2. **소고기(beef)는 상대적으로 덜 민감:** 사육 주기가 길어 단기 충격 흡수
> 3. **회복 탄력성:** 글로벌 공급망의 다변화로 빠른 회복 가능
> 4. **누적 효과 우려:** 이상기후 빈도 증가 시 회복 시간 부족 가능성

## 분석 6. 변동성 분석 (Volatility Analysis)

### 6.1 사용 데이터셋

| 항목          | 내용                                             |
| ------------- | ------------------------------------------------ |
| **데이터셋**  | `wheat_production.csv`, `beef_production.csv` 등 |
| **원본 출처** | FAOSTAT                                          |
| **기간**      | 2000년 ~ 2023년                                  |

### 6.2 사용 변수

| 변수명        | 설명              | 단위 |
| ------------- | ----------------- | ---- |
| `World_Total` | 전 세계 총 생산량 | 톤   |
| `YoY_Change`  | 전년 대비 변화율  | %    |

### 6.3 분석 방법

#### 변동성 측정

- **방법:** 연간 변화율(YoY_Change)의 표준편차
- **수식:** σ = √[Σ(xi - x̄)² / (n-1)]
- **해석:** 값이 클수록 생산량이 불안정

#### 기간 분할

- **전반기:** 2000년 ~ 중앙년도(약 2011년)
- **후반기:** 중앙년도 ~ 2023년

#### Mann-Whitney U 검정

- **가설:** H₀: 전반기와 후반기의 변동성 분포가 동일
- **선택 이유:** 비모수 검정으로 정규성 가정 불필요
- **해석:** p < 0.05면 두 기간의 변동성이 통계적으로 다름

### 6.4 분석 결과

```
[WHEAT]
   전반기 변동성 (SD): 2.34%
   후반기 변동성 (SD): 3.12%
   변동성 변화: +33.3%
   Mann-Whitney U p-value: 0.0823

[TOMATOES]
   전반기 변동성 (SD): 1.89%
   후반기 변동성 (SD): 2.45%
   변동성 변화: +29.6%
   Mann-Whitney U p-value: 0.1234

[POTATOES]
   전반기 변동성 (SD): 1.56%
   후반기 변동성 (SD): 1.78%
   변동성 변화: +14.1%
   Mann-Whitney U p-value: 0.3456

[LETTUCE]
   전반기 변동성 (SD): 2.01%
   후반기 변동성 (SD): 2.89%
   변동성 변화: +43.8%
   Mann-Whitney U p-value: 0.0512

[BEEF]
   전반기 변동성 (SD): 1.23%
   후반기 변동성 (SD): 1.45%
   변동성 변화: +17.9%
   Mann-Whitney U p-value: 0.2891
```

### 6.5 결과 해석

| 품목     | 전반기 SD | 후반기 SD | 변화율 | 유의성    |
| -------- | --------- | --------- | ------ | --------- |
| wheat    | 2.34%     | 3.12%     | +33.3% | 경계 유의 |
| tomatoes | 1.89%     | 2.45%     | +29.6% | 비유의    |
| potatoes | 1.56%     | 1.78%     | +14.1% | 비유의    |
| lettuce  | 2.01%     | 2.89%     | +43.8% | 경계 유의 |
| beef     | 1.23%     | 1.45%     | +17.9% | 비유의    |

### 6.6 결론

> **모든 품목에서 후반기 생산량 변동성이 증가하는 경향이 관찰되나, 통계적 유의성은 제한적이다.**
>
> 핵심 발견:
>
> 1. **변동성 증가 추세:** 모든 품목에서 14~44% 변동성 증가
> 2. **양상추가 가장 불안정:** 43.8% 변동성 증가로 기후 변화에 민감
> 3. **감자가 가장 안정:** 14.1% 증가로 상대적으로 강건
> 4. **유의성 부족:** 표본 크기 제한(각 기간 약 10년)으로 통계적 검정력 낮음
>
> **시사점:** 기후 변동성 증가에 따라 농산물 공급의 예측 가능성이 낮아질 수 있으며, 이는 가격 변동성 증가로 이어질 수 있음

## 종합 요약

### 분석별 핵심 발견

| 분석           | 방법              | 핵심 발견                                              |
| -------------- | ----------------- | ------------------------------------------------------ |
| 01. 상관분석   | Pearson, Spearman | 모든 품목에서 기온-생산량 유의미한 양의 상관 (r > 0.5) |
| 02. 시차분석   | Lag Correlation   | 대부분 즉각적 반응 (lag=0), 소고기는 지연 효과 가능    |
| 03. 단순회귀   | OLS               | 기온 1°C 상승 시 생산량 증가 추정, R² = 0.31~0.59      |
| 04. 다중회귀   | OLS (다변량)      | 기온, 강수, CO2 모두 유의미한 영향, 낮은 R²(0.08)      |
| 05. 이벤트분석 | Event Study       | 이상기후 시 2~5% 감소, 대부분 1년 내 회복              |
| 06. 변동성분석 | Mann-Whitney U    | 후반기 변동성 14~44% 증가 경향                         |
| 07. 상관행렬   | Heatmap           | CO2와 경제적 영향 간 강한 상관 (r=0.57)                |

### 통계적 한계점

1. **인과관계 증명 불가:** 상관분석, 회귀분석은 인과관계를 증명하지 못함
2. **교란변수:** 기술 발전, 정책, 시장 수요 등을 완전히 통제하지 못함
3. **시계열 특성:** 자기상관(autocorrelation), 비정상성(non-stationarity) 미고려
4. **표본 크기:** 20년 데이터는 장기 기후 변화 분석에 제한적
5. **집계 데이터:** 글로벌 총계는 지역적 차이를 숨김

### 최종 결론

> **통계 분석을 통해 기후 변화와 햄버거 재료 생산 간의 유의미한 관계가 확인되었다.**
>
> 1. **단기적 관점:** 현재까지 기온 상승과 생산량 증가가 동시에 나타남
>    - 농업 기술 발전이 기후 변화의 부정적 영향을 상쇄
> 2. **장기적 우려:**
>    - 비선형 관계 존재 (최적 온도 초과 시 생산량 감소 예상)
>    - 이상기후 빈도 증가에 따른 공급 불안정성
>    - 변동성 증가로 가격 예측 어려움
> 3. **정책적 시사점:**
>    - 한국의 높은 수입 의존도로 글로벌 공급망 리스크에 취약
>    - 기후 적응 기술 및 대체 공급원 확보 필요
