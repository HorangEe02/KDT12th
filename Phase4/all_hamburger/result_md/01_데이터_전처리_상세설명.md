#### 대용량 파일 처리 방법 (Chunked Reading)

```python
def load_faostat_production(data_dir, chunksize=500000):
    """
    대용량 파일을 청크 단위로 읽으면서 필요한 데이터만 필터링
    """
    chunks = []
    total_rows = 0

    for chunk in pd.read_csv(filepath, chunksize=chunksize, encoding='latin-1'):
        total_rows += len(chunk)
        # 분석 대상 품목만 필터링
        filtered = chunk[chunk['Item'].isin(target_items)]
        if len(filtered) > 0:
            chunks.append(filtered)

    df = pd.concat(chunks, ignore_index=True)
    return df
```

#### Chunked Reading을 사용한 이유

| 이유              | 설명                                        |
| ----------------- | ------------------------------------------- |
| **메모리 효율성** | 545MB 전체를 메모리에 올리지 않고 순차 처리 |
| **선택적 필터링** | 필요한 품목만 추출하여 메모리 사용량 최소화 |
| **확장성**        | 더 큰 파일도 동일한 방식으로 처리 가능      |

## 5. 품목별 데이터 추출 및 피벗

### 5.1 피벗 테이블 생성

#### 피벗 변환 목적

- **원본 형태:** 국가별, 연도별 개별 행으로 존재
- **목표 형태:** 연도를 인덱스로, 국가를 컬럼으로 하는 행렬

#### 변환 전 (Long Format):

| Year | Area  | Item  | Element    | Value    |
| ---- | ----- | ----- | ---------- | -------- |
| 2000 | USA   | Wheat | Production | 60000000 |
| 2000 | China | Wheat | Production | 99000000 |
| 2001 | USA   | Wheat | Production | 62000000 |
| ...  | ...   | ...   | ...        | ...      |

#### 변환 후 (Pivot Table):

| Year | USA      | China    | Russia   | ... | World_Total |
| ---- | -------- | -------- | -------- | --- | ----------- |
| 2000 | 60000000 | 99000000 | 34500000 | ... | 585000000   |
| 2001 | 62000000 | 95000000 | 36000000 | ... | 590000000   |
| ...  | ...      | ...      | ...      | ... | ...         |

#### 피벗 코드

```python
def create_item_production_pivot(df, item_name, element='Production'):
    mask = (df['Item'] == item_name) & (df['Element'] == element)
    df_filtered = df[mask].copy()

    df_pivot = df_filtered.pivot_table(
        index='Year',
        columns='Area',
        values='Value',
        aggfunc='sum'
    ).reset_index()

    # 전 세계 합계 컬럼 추가
    numeric_cols = [c for c in df_pivot.columns if c != 'Year']
    df_pivot['World_Total'] = df_pivot[numeric_cols].sum(axis=1)

    return df_pivot
```

```python
                'World_Production_Tonnes': row['World_Total']
            }
            # 기온 데이터 추가
            record['Temp_Anomaly_C'] = temp_value
            integrated_data.append(record)

    df_integrated = pd.DataFrame(integrated_data)

    # 연간 변화율 계산
    df_integrated = df_integrated.sort_values(['Item_Key', 'Year'])
    df_integrated['YoY_Change_Pct'] = df_integrated.groupby('Item_Key')['World_Production_Tonnes'].pct_change() * 100

    return df_integrated
```

### 6.3 연간 변화율(YoY) 계산

#### 계산 공식

```
YoY_Change_Pct = (현재 연도 생산량 - 전년도 생산량) / 전년도 생산량 × 100
```

#### 사용 이유

| 이유            | 설명                                     |
| --------------- | ---------------------------------------- |
| **추세 분석**   | 절대값이 아닌 변화율로 품목 간 비교 가능 |
| **변동성 측정** | 생산량 변동의 크기를 정량화              |
| **이상치 탐지** | 급격한 변화(이상기후 등) 탐지            |
