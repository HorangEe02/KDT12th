# 🗺️ Tab 2. 동선 지도 — 기능 설명서

> **"집에서 구장까지 얼마나 걸리지? 가는 길에 뭐 먹고 갈까?"**
> 원정 응원의 현실적인 동선 고민을 한 지도 위에 풀어놓는 것이 이 탭의 역할입니다.

**라우트**: `/map` · **배포 URL**: [my-web-app--mini12-310f5.asia-east1.hosted.app/map](https://my-web-app--mini12-310f5.asia-east1.hosted.app/map)

---

## 📖 起 (기) — 왜 필요한가? 문제 제기

### 원정 응원, 지도 앞에서 막히는 이유

원정 경기 하나를 가려면 팬은 이런 작업을 반복합니다:

> **작업 1 — "경기장이 어디였더라?"**
> 네이버지도를 열어 "사직야구장" 검색.
>
> **작업 2 — "근처 맛집 뭐 있지?"**
> 다시 블로그·인스타·유튜브를 돌아다니며 주변 맛집 검색.
>
> **작업 3 — "지하철로 갈까 차로 갈까?"**
> 카카오맵으로 경로를 뽑고, 다시 대중교통·자차를 비교.
>
> **작업 4 — "경기장 근처 숙소는?"**
> 호텔 앱·에어비앤비·부킹닷컴을 또 따로 엽니다.

이 4가지를 **앱 4~5개** 를 왔다갔다 하며 처리하는 동안 배터리도 줄고, 정보는 흩어지고, 결국 **계획 세우는 것 자체가 피곤**해집니다.

### 이 탭의 약속

**"경기장 · 맛집 · 숙박 · 관광지 + 출발지 → 경기장 경로"** 를 한 지도 위에 겹쳐 보여줍니다. 지도 토글로 원하는 카테고리만 켜고 끄며, 출발지를 바꾸면 즉시 새 경로가 그려집니다.

## 🚀 承 (승) — 무엇을 하는가? 기능 소개

### 기능 6가지

#### 1. 4-레이어 지도
- **⚾ 경기장** · 🍽 음식점 · 🏨 숙박 · 🎡 관광지 를 각각 다른 색 마커로 표시
- 우측 상단 **토글 박스** 로 원하는 레이어만 표시 가능
- 예: "음식점만 보고 싶어" → 체크박스 3개 해제

#### 2. 3단계 길찾기 안전망
- 출발지에서 경기장까지 **자동으로 경로 탐색**
- "정밀 경로(카카오)" → "최적 경로(오픈소스)" → "직선 거리(안전망)" 순으로 단계별 시도
- 어떤 상황에서도 **반드시 결과를 돌려줍니다** (자세한 원리는 아래 轉 섹션)

#### 3. 출발지 변경
- 서울역 · 강남역 · 수원역 · 대전역 4종 프리셋 버튼
- GPS 허용 시 **"내 위치"** 옵션으로 현재 좌표 사용
- 버튼 한 번 누를 때마다 경로가 다시 계산됨

#### 4. 경기 변경 (=도착지 변경)
- 모바일: 도착지 카드 탭 → **경기 선택 시트** 오픈
- 다른 경기를 고르면 경기장 좌표가 바뀌고 경로도 자동 갱신

#### 5. 경유지 추가
- 가는 길에 들를 **맛집·숙소·관광지 1개** 를 동선에 추가
- 예: "고척 가기 전에 원할머니보쌈 들르기"

#### 6. 외부 지도 앱 연동
- **"길 안내 시작"** 버튼 탭
- 네이버지도 · 카카오맵 중 선택 → **딥링크**로 해당 앱 자동 실행
- 실제 원정 당일에는 외부 앱 내비게이션이 더 편하기 때문

### 화면 예시

**💻 데스크톱**
```
┌─ 🗺 원정 동선 지도 ──────────────────────────────┐
│ 삼성 · 2026-04-25 @ 대구 · vs 한화                │
├─ [경기 선택 ▼] [서울역] [강남역] [수원역] [대전역] │
├─ 📍 경로 요약: 최적 · 145km · 2시간 10분           │
├─ 🗺 Leaflet 지도 (4 레이어 토글 + 경로 라인) ────┤
│                                                   │
│ [경기장 마커] ──── 경로 ──── [출발지 마커]          │
│                                                   │
└───────────────────────────────────────────────────┘
```

**📱 모바일**
- 전체 화면 풀스크린 지도
- 하단에 **"경기일 동선"** 플로팅 카드
  - 3 stops (출발지 · 경유지 · 도착지) 각각 탭하여 변경 가능
  - **"길 안내 시작"** CTA 버튼

## ⚙️ 轉 (전) — 어떻게 만들었는가? 기술과 원리

> 지도와 경로 탐색 기술을 **비유와 예시**로 풀어씁니다.

### 🗺️ Leaflet — "지도 기능 덩어리 라이브러리"

**쉽게 말하면**:
> "카카오맵·구글맵 같은 지도를 내가 만든 웹 페이지에 심고 싶을 때 쓰는 도구입니다."

- 타일(tile): 지도는 작은 정사각형 이미지 조각들을 격자로 붙여 만듭니다. Leaflet이 이 조각들을 자동으로 불러와 이어 붙입니다.
- 마커(marker): 지도 위 핀. 색·모양·클릭 반응 등을 자유롭게 꾸밀 수 있습니다.
- 레이어(layer): "맛집만 보이기" 같은 ON/OFF 그룹.

**왜 Leaflet?**: 무료·오픈소스이며, 카카오/네이버 지도처럼 **API 사용료가 없어** 학생·개인 프로젝트에 부담이 없습니다.

### 🌍 OpenStreetMap — "공공 위키피디아 같은 지도"

지도 이미지는 **OpenStreetMap(OSM)** 이라는 전 세계 자원봉사자들이 만든 공공 지도를 씁니다.
- 상업적 지도(구글·카카오)와 달리 **무료**
- 약점: 한국의 일부 최신 건물 정보는 다소 느림
- 장점: 가맹 없이 누구나 쓸 수 있음

### 🎯 3단계 길찾기 안전망 (3-tier Fallback) — **이 프로젝트의 심장**

**쉽게 말하면**:
> "엘리베이터 고장나면 계단, 그것도 막히면 걸어 내려가는 것처럼, **경로 계산 방법을 3단계로 준비해두고 하나씩 시도**합니다."

| 단계 | 방법 | 비유 |
|---|---|---|
| 1단계 | **카카오 모빌리티 API** | 카카오택시가 쓰는 프리미엄 내비 — 통행료·실시간 교통 포함 |
| 2단계 | **OSRM (오픈소스)** | 전 세계 연구자들이 만든 무료 지도 경로 탐색 |
| 3단계 | **Haversine (직선 거리)** | "서울 → 대구 직선 거리 238km" 같은 수학 공식 |

**작동 시나리오**:
```
[1단계] 카카오 API 호출
   │
   ├─ 성공 → "정밀" 배지 · 통행료·실제 도로 경로 반환
   │
   └─ 실패 (API 키 없음·401·5초 초과)
       │
       ▼
[2단계] OSRM 호출
   │
   ├─ 성공 → "최적" 배지 · 실제 도로 경로 반환
   │
   └─ 실패 (네트워크·5초 초과)
       │
       ▼
[3단계] 직선 거리 계산
   │
   └─ 항상 성공 → "직선" 배지 + 점선 라인
```

**왜 이렇게 복잡하게?**:
- 카카오 API는 **유료 승인**이 필요하고, 승인 못 받으면 항상 실패합니다
- OSRM은 **공개 서버**라 가끔 느리거나 다운됩니다
- 결국 **"경로를 보여주지 못하는 상황"** 을 만들지 않으려면 마지막 보루(직선 거리)가 필요합니다

이 방식은 실제로 작동 중입니다 — 현재 배포된 서비스에서 카카오 승인이 없어 **자동으로 OSRM(2단계)로 넘어가 정상 동작**하고 있습니다.

### 💾 경로 캐시 — "한 번 계산한 건 기억해두기"

같은 출발지·도착지 조합이 들어오면, 서버는 메모리에 저장된 결과를 그대로 반환합니다.
- 첫 번째 계산: 약 **828ms**
- 두 번째부터: 약 **20ms** (**40배 빠름**)
- 비유: "엄마가 어제 물어본 레시피 또 물어보면 바로 대답하는 것"

### 📱 모바일 하단 시트 — vaul

iPhone의 Apple Music 아래에서 올라오는 패널을 본 적 있나요? 이런 **"스르륵 올라오는 시트"** UI를 `vaul` 이라는 라이브러리로 구현했습니다.
- 손가락으로 드래그해서 높이 조절
- 배경 탭하면 닫힘
- 스냅 포인트(62% / 92%)가 뷰포트에 따라 자동 조정

### 🛡️ safe-area-inset — "아이폰 노치 피하는 마법"

iPhone 14/15 Pro 의 **Dynamic Island(검은 섬)** · 하단 **홈 인디케이터(가로 막대)** 자리에 지도가 가려지지 않도록 처리했습니다.

```css
top: calc(4rem + env(safe-area-inset-top));     /* 상단 노치 피하기 */
bottom: calc(5rem + env(safe-area-inset-bottom)); /* 하단 인디케이터 피하기 */
```

비유: **"방 배치할 때 기둥을 피해서 가구를 놓는 것"**. 기기마다 기둥 위치가 다르지만, 운영체제가 "기둥 크기"를 알려주면 자동으로 피합니다.

📂 10 구장 좌표 · 주소 · 주변 POI (맛집·숙소·관광지)
📂 현재 선택한 경기 (응원팀 원정 일정)
       │
       ▼
 ┌──────────────────────────────────┐

       │

       ▼
 ┌──────────────────────────────────┐

       │
       ▼

## 🎯 結 (결) — 어떤 가치를 만들었는가? 결과와 의미

### 숫자로 본 성과

| 지표 | 결과 |
|---|---|
| 길찾기 성공률 | **100%** (3단계 안전망 덕에 어떤 상황에서도 결과 반환) |
| 실측 경로 | 잠실 → 수원 33.5km, 537 지점 연결, 약 0.8초 |
| 캐시 적중 시 응답 | **20ms** (초기 대비 40배 단축) |
| 카카오 승인 없어도 동작 | ✅ OSRM 자동 폴백 |
| 모바일 자동 테스트 | iPhone SE · 14 Pro · iPad **전 환경 통과** |
| 라이브 주소 | [배포 완료 ✅](https://my-web-app--mini12-310f5.asia-east1.hosted.app/map) |

### 사용자에게 남기는 것

**"지도 하나로 경기장 · 맛집 · 숙소 · 관광지 · 경로까지. 앱 5개 열 일이 1개로 줄었습니다."**

원정 당일에는 **"길 안내 시작"** 버튼 탭 한 번으로 네이버지도/카카오맵으로 자연스럽게 넘어가, **계획은 우리 앱에서 · 실제 내비는 전문 앱에서** 각각 최적을 제공합니다.

### 기술적 의의

- **3-tier 안전망 설계**: 상용 API 사용료가 없는 학생·개인 프로젝트에서도 **완전한 길찾기 서비스 구현 가능**을 증명
- **서버 메모리 캐시**: 같은 좌표 반복 조회 시 40배 빠른 응답 → 무료 티어에서도 안정 운영
- **safe-area + 풀스크린**: iPhone Dynamic Island · 홈 인디케이터 · 다양한 Android 기기에서 **지도가 잘려 보이는 일 없음**
- **외부 앱 딥링크**: 서비스 안에서 모든 걸 끝내려 하지 않고, 사용자 습관(네이버지도 등)을 존중하는 설계

## 🔍 부록 — 개발자용 상세 정보

아래는 코드를 다루는 개발자를 위한 참조입니다. 일반 독자는 건너뛰어도 좋습니다.

### A. 경로 API 응답 스키마

```ts
{
  source: "kakao" | "osrm" | "haversine",
  polyline: [number, number][],   // [lat, lng] 쌍 배열
  distance_m: number,
  duration_sec: number | null,
  toll_fare_krw: number | null,
  fallback?: boolean,
  attempts: Array<{
    provider: string,
    ok: boolean,
    ms: number,
    error?: string
  }>
}
```

- Endpoint: `GET /api/route?o_lat=...&o_lng=...&d_lat=...&d_lng=...` · `POST /api/route`
- Zod tuple `[number, number]` 검증 · 5초 `AbortController` 타임아웃
- 캐시 키: 좌표 5자리 반올림 `${lat1},${lng1}-${lat2},${lng2}`

### B. 쿼리 파라미터

| Param | 기본값 | 설명 |
|---|---|---|
| `team` | profile.favoriteTeam | 응원팀 |
| `start` · `end` | 시즌 개막 ~ 종료 | 기간 필터 |
| `game` | `games[0].game_id` | 도착지 결정 |
| `origin` | `"seoul"` | 프리셋 키 or `custom` |
| `lat` · `lng` | — | `origin=custom` 일 때 좌표 |
