## 2. 왜 이 주제를 선택했는가?

### 2.1 제조업이 직면한 현실적 위기

대한민국 제조업은 GDP의 약 25%를 차지하는 핵심 산업이지만, 현재 세 가지 구조적 위기에 직면해 있습니다.

**첫째, 생산인구 감소와 숙련공 은퇴입니다.** 통계청에 따르면 한국의 생산가능인구(15~64세)는 2020년 3,738만 명에서 2030년 3,395만 명으로 약 343만 명이 줄어들 전망입니다. 제조 현장에서 수십 년간 경험을 쌓아온 품질 검사 숙련공들이 은퇴하면서, 그들의 눈과 손에 의존하던 육안 검사 체계가 근본적으로 흔들리고 있습니다.

**둘째, 수작업 품질 검사의 한계입니다.** 사람의 눈에 의존하는 품질 검사는 피로도, 주관적 판단, 속도 제한이라는 태생적 한계를 갖고 있습니다. 교대 근무 8시간 동안 검사원의 집중력은 시간이 지남에 따라 현저히 저하되며, 동일한 제품이라도 검사자에 따라 판정이 달라지는 일관성 문제가 발생합니다.

**셋째, 글로벌 품질 경쟁의 심화입니다.** BMW, 지멘스 등 글로벌 제조 기업들은 이미 AI 기반 품질 검사 시스템을 도입하여 불량률을 획기적으로 줄이고 있습니다. 국내 기업들이 이 흐름에 뒤처지면 글로벌 공급망에서 경쟁력을 잃게 됩니다.

### 2.2 수업 내용과의 직접적 연결

| 수업 내용 | 프로젝트 적용 |
|----------|-------------|
| CNN 이미지 분류 (ResNet, VGG, 전이학습) | 소주제 A — 주조 제품 불량/정상 자동 분류 |
| U-Net 세그먼테이션 (Dice Loss, Skip Connection) | 소주제 B — 자석 타일 표면 결함 세그먼테이션 |
| YOLO 객체 탐지 (바운딩 박스, mAP, NMS) | 소주제 C — PCB 기판 결함 위치 탐지 |
| BERT 파인튜닝 / LSTM (텍스트 분류, 토큰화) | 소주제 D — 설비 고장 유형 예측 |

## 3. 프로젝트를 통해 얻을 수 있는 가치 및 인사이트

### 3.1 기술적 가치

하나의 도메인(제조) 안에서 이미지 분류, 세그먼테이션, 객체 탐지, 자연어 처리라는 4가지 서로 다른 딥러닝 접근 방식을 동시에 경험합니다. 이를 통해 "어떤 문제에 어떤 기법을 적용해야 하는가"에 대한 실전적 판단력을 기를 수 있습니다.

| 문제 유형 | 적합한 기법 | 프로젝트 적용 |
|----------|-----------|----------------|
| "이 제품은 불량인가 정상인가?" | CNN 이미지 분류 | 소주제 A |
| "결함이 정확히 어디에 있는가?" | U-Net 세그먼테이션 | 소주제 B |
| "이미지 안에 어떤 결함들이 있는가?" | YOLO 객체 탐지 | 소주제 C |
| "이 설비는 왜 고장났는가?" | NLP 텍스트 분류 | 소주제 D |

### 3.2 비즈니스 가치

- **비용 절감**: AI 비전 검사로 24시간 무인 운영, 불량 유출 클레임/리콜 비용 사전 차단
- **생산성 향상**: 수작업 대비 검사 속도 10배 이상, 검사자 간 편차 제거
- **예지보전**: 설비 고장 사전 예측으로 비계획 정지 시간 30~50% 감소

## 6. 소주제별 상세 계획

### 소주제 A. 주조 제품 불량/정상 자동 분류

| 항목 | 내용 |
|------|------|
| 핵심 기술 | CNN 전이학습 (ResNet50, VGG16, EfficientNet) |
| 데이터셋 | Casting Product Image Data (7,348장, 2클래스) |
| 데이터 출처 | https://www.kaggle.com/datasets/ravirajsinh45/real-life-industrial-dataset-of-casting-product |
| 주요 과제 | 모델별 정확도 비교, Grad-CAM 시각화, 데이터 증강 효과 실험 |

### 소주제 B. 자석 타일 표면 결함 세그먼테이션 ✅ (변경)

| 항목 | 내용 |
|------|------|
| 핵심 기술 | U-Net (인코더-디코더 + Skip Connection) |
| 데이터셋 | Magnetic Tile Surface Defects (1,344장, 5종 결함 + 정상) |
| 데이터 출처 | https://www.kaggle.com/datasets/alex000kim/magnetic-tile-surface-defects |
| 주요 과제 | 다중 결함 유형 세그먼테이션, Dice Loss 적용, 소량 데이터 증강, 결함 유형별 성능 분석 |

**이 데이터셋을 선택한 이유:**

- **제조 공정 직접 연결**: 영구자석 모터의 핵심 부품인 자석 타일의 표면 결함을 탐지하는 실제 제조 품질관리 과제
- **픽셀 레벨 마스크 제공**: RLE 디코딩 없이 세그먼테이션 마스크가 바로 제공되어 U-Net 학습에 집중 가능
- **5종 결함 유형**: Blowhole(기공), Break(파손), Crack(균열), Fray(마모), Uneven(불균일)으로 결함 유형별 성능 분석 가능
- **소량 데이터 도전**: 결함 이미지 392장이라는 현실적 제약 → 강한 데이터 증강 전략 필수
- **산업 현실 반영**: 중국 저장성 자석 타일 생산기지에서 전체 인력의 ~75%가 수작업 검사에 투입되는 현실

### 소주제 C. PCB 기판 결함 자동 탐지

| 항목 | 내용 |
|------|------|
| 핵심 기술 | YOLOv8 (Ultralytics) |
| 데이터셋 | PCB Defects Dataset (693장, 6 결함 유형) |
| 데이터 출처 | https://www.kaggle.com/datasets/akhatova/pcb-defects |
| 주요 과제 | XML→YOLO 어노테이션 변환, 사전학습 가중치 파인튜닝, mAP 평가 |

### 소주제 D. 설비 고장 유형 예측

| 항목 | 내용 |
|------|------|
| 핵심 기술 | LSTM / BERT 텍스트 분류 |
| 데이터셋 | Machine Predictive Maintenance Classification (10,000건) |
| 데이터 출처 | https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification |
| 주요 과제 | 센서 수치→텍스트 변환, 고장 유형 5종 분류, 클래스 불균형 대응 |
