## 2. 왜 이 주제를 선택했는가?

### 2.1 제조업이 직면한 현실적 위기

대한민국 제조업은 GDP의 약 25%를 차지하는 핵심 산업이지만, 현재 세 가지 구조적 위기에 직면해 있습니다.

**첫째, 생산인구 감소와 숙련공 은퇴입니다.** 통계청에 따르면 한국의 생산가능인구(15~64세)는 2020년 3,738만 명에서 2030년 3,395만 명으로 약 343만 명이 줄어들 전망입니다. 제조 현장에서 수십 년간 경험을 쌓아온 품질 검사 숙련공들이 은퇴하면서, 그들의 눈과 손에 의존하던 육안 검사 체계가 근본적으로 흔들리고 있습니다.

**둘째, 수작업 품질 검사의 한계입니다.** 사람의 눈에 의존하는 품질 검사는 피로도, 주관적 판단, 속도 제한이라는 태생적 한계를 갖고 있습니다. 교대 근무 8시간 동안 검사원의 집중력은 시간이 지남에 따라 현저히 저하되며, 동일한 제품이라도 검사자에 따라 판정이 달라지는 일관성 문제가 발생합니다.

**셋째, 글로벌 품질 경쟁의 심화입니다.** BMW, 지멘스 등 글로벌 제조 기업들은 이미 AI 기반 품질 검사 시스템을 도입하여 불량률을 획기적으로 줄이고 있습니다. 국내 기업들이 이 흐름에 뒤처지면 글로벌 공급망에서 경쟁력을 잃게 됩니다.

### 2.2 정부 정책과의 연계

중소벤처기업부는 2026년까지 스마트공장 3만 개소 구축을 목표로 추진 중이며, 기초 단계(4,000만 원 지원)부터 고도화 단계(3억 원 지원)까지 체계적인 지원 사업을 운영하고 있습니다. 스마트 제조 도입의 가장 큰 목적은 생산 효율성 향상(56.5%)과 품질 개선(37.1%)으로, 본 프로젝트의 방향성과 정확히 일치합니다.

### 2.3 수업 내용과의 직접적 연결

본 프로젝트는 K-Digital Training 딥러닝 과정에서 학습한 핵심 기술들을 실제 산업 문제에 적용하는 것을 목표로 합니다.

| 수업 내용 | 프로젝트 적용 |
|----------|-------------|
| CNN 이미지 분류 (ResNet, VGG, 전이학습) | 소주제 A — 주조 제품 불량/정상 자동 분류 |
| U-Net 세그먼테이션 (Dice Loss, Skip Connection) | 소주제 B — 산업 시설 표면 균열 세그먼테이션 |

| BERT 파인튜닝 / LSTM (텍스트 분류, 토큰화) | 소주제 D — 설비 고장 유형 예측 |

## 3. 프로젝트를 통해 얻을 수 있는 가치 및 인사이트

### 3.1 기술적 가치

**다양한 딥러닝 기법의 통합 경험**

하나의 도메인(제조) 안에서 이미지 분류, 세그먼테이션, 객체 탐지, 자연어 처리라는 4가지 서로 다른 딥러닝 접근 방식을 동시에 경험합니다. 이를 통해 "어떤 문제에 어떤 기법을 적용해야 하는가"에 대한 실전적 판단력을 기를 수 있습니다.

| 문제 유형 | 적합한 기법 | 본 프로젝트 적용 |
|----------|-----------|----------------|
| "이 제품은 불량인가 정상인가?" | CNN 이미지 분류 | 소주제 A |
| "균열이 정확히 어디에 있는가?" | U-Net 세그먼테이션 | 소주제 B |
| "이미지 안에 어떤 결함들이 있는가?" | YOLO 객체 탐지 | 소주제 C |
| "이 설비는 왜 고장났는가?" | NLP 텍스트 분류 | 소주제 D |

**전이학습의 산업적 효용 검증**

ImageNet으로 사전학습된 ResNet/VGG 모델을 제조 도메인에 파인튜닝하여, 적은 데이터로도 높은 정확도를 달성할 수 있는지 실험합니다. 이는 데이터 확보가 어려운 중소 제조업체에서 AI를 도입할 때 가장 현실적인 전략입니다.

**설명 가능한 AI(XAI)의 가능성**

Grad-CAM 히트맵을 통해 "AI가 어디를 보고 불량이라고 판단했는지"를 시각적으로 보여줍니다. 이는 품질 검사원이 AI의 판정 결과를 신뢰하고 수용하기 위한 핵심 요소입니다.

### 3.2 비즈니스 가치

**비용 절감 효과**

AI 비전 검사 시스템을 도입하면 24시간 무인 운영이 가능하여 인건비를 절감하고, 불량 유출로 인한 클레임 비용과 리콜 비용을 사전에 차단할 수 있습니다.

**생산성 향상**

수작업 대비 검사 속도가 10배 이상 빨라지며, 일관된 품질 기준으로 판정하므로 검사자 간 편차가 사라집니다.

**예지보전을 통한 가동률 향상**

설비 고장을 사전에 예측하여 계획된 시점에 정비를 수행함으로써, 비계획 정지 시간을 30~50% 줄일 수 있습니다.

### 3.3 학습 인사이트

본 프로젝트를 수행하면서 다음과 같은 인사이트를 얻을 수 있습니다.

- **데이터 품질의 중요성**: 실제 제조 데이터는 클래스 불균형, 촬영 조건 변화, 라벨링 노이즈 등 교과서적이지 않은 문제들이 존재하며, 이를 어떻게 처리하느냐가 모델 성능을 좌우합니다.
- **평가 지표의 의미**: 단순 Accuracy가 아닌, Precision/Recall/F1-Score/mAP/Dice 등 과제별로 적합한 평가 지표를 선택하는 판단력을 기릅니다.
- **도메인 지식의 필요성**: "어떤 결함이 치명적이고, 어떤 것은 허용 가능한가"와 같은 제조 도메인 지식이 모델 설계와 임계값 설정에 직접 영향을 미칩니다.

## 6. 소주제별 상세 계획

### 소주제 A. 주조 제품 불량/정상 자동 분류

| 항목 | 내용 |
|------|------|
| 담당 | 김현정|
| 핵심 기술 | CNN 전이학습 (ResNet50, VGG16, EfficientNet) |
| 데이터셋 | Casting Product Image Data (7,348장, 2클래스) |
| 데이터 출처 | https://www.kaggle.com/datasets/ravirajsinh45/real-life-industrial-dataset-of-casting-product |
| 주요 과제 | 모델별 정확도 비교, Grad-CAM 시각화, 데이터 증강 효과 실험 |

### 소주제 B. 산업 시설 표면 균열 세그먼테이션 ✅ (변경)

| 항목 | 내용 |
|------|------|
| 담당 | 박준영 |
| 핵심 기술 | U-Net (인코더-디코더 + Skip Connection) |
| 데이터셋 | Crack Segmentation Dataset (11,200장, 바이너리 마스크 포함) |
| 데이터 출처 | https://www.kaggle.com/datasets/lakshaymiddha/crack-segmentation-dataset |
| 대안 데이터 | Concrete Crack Segmentation Dataset — https://www.kaggle.com/datasets/motono0223/concrete-crack-segmentation-dataset |
| 주요 과제 | U-Net 구현, Dice Loss 적용, 균열 영역 정밀 분할, 마스크 오버레이 시각화 |

**변경 사유**: 기존 소주제(Severstal 철강 결함)의 데이터셋을 이전 미니프로젝트에서 사용하여, 새로운 도메인의 세그먼테이션 경험을 쌓기 위해 산업 시설 균열 탐지로 변경하였습니다.

**Crack Segmentation Dataset 상세 정보:**

| 항목 | 내용 |
|------|------|
| 이미지 수 | 약 11,200장 (12개 공개 데이터셋 통합) |
| 이미지 크기 | 448×448 (정사각형, 통일됨) |
| 마스크 형식 | 바이너리 마스크 (0=배경, 255=균열) — PNG |
| 대상 | 콘크리트, 포장도로, 교량, 공장 바닥 등 산업 구조물 |
| 분류 | 이진 세그먼테이션 (균열 vs 배경) |
| 폴더 구조 | Train/Test 사전 분리 완료 (images/ + masks/) |
| 특이사항 | "noncrack*" 패턴의 무결함 이미지 포함 (필터링 가능) |

**이 데이터셋이 스마트 팩토리에 적합한 이유:**

- 공장 바닥, 벽면, 기반 구조물의 균열은 제조 시설의 **구조 안전성**에 직결됩니다.
- 스마트 팩토리의 **예방적 시설 관리** 체계에서 AI 기반 균열 탐지는 핵심 요소입니다.
- 이진 세그먼테이션(균열/배경)으로 U-Net 학습이 직관적이며, Dice Loss 적용 효과를 명확히 관찰할 수 있습니다.
- 11,200장의 충분한 데이터로 안정적인 학습이 가능합니다.

## 7. 기대 효과 종합

### 7.1 정량적 기대 효과 요약

```
                        Before (수작업)              After (AI)
                    ┌─────────────────────┐    ┌─────────────────────┐
  검사 정확도        │      80~85%         │ →  │      95~99%         │
  검사 속도          │    10~30초/개        │ →  │    0.1~0.5초/개      │
  일일 검사량        │    ~1,400개/일       │ →  │   ~86,400개/일       │
  불량 유출률        │      15~20%         │ →  │       1~5%          │
  검사 일관성        │    검사자별 편차 大   │ →  │     편차 0%          │
  설비 정지 시간     │    연 110시간        │ →  │    연 55~77시간      │
  운영 시간          │     8시간/일         │ →  │     24시간/일        │
                    └─────────────────────┘    └─────────────────────┘
```

### 7.2 정성적 기대 효과

- **숙련공 의존도 탈피**: AI가 일관된 품질 기준을 제공하여, 신입 작업자도 즉시 품질 관리 업무 수행 가능
- **데이터 기반 의사결정**: 감에 의존하던 품질 판정을 수치와 근거에 기반한 의사결정으로 전환
- **예방적 품질 관리**: 불량이 발생한 후 대응하는 방식에서, 불량 발생 전에 원인을 예측하고 예방하는 체계로 전환
- **시설 안전 강화**: AI 기반 균열 세그먼테이션으로 공장 구조물의 안전성을 상시 모니터링
- **글로벌 경쟁력 확보**: AI 품질 검사 시스템은 ISO 등 국제 품질 인증 시 가산점 요소로 작용

## 9. 개인 추가 작업 — FORGE SENTINEL 대시보드

> 아래 내용은 팀 프로젝트 종료 후 **개인적으로 추가 수정 및 보완**한 사항입니다.

### 9.1 대시보드 개요

팀 프로젝트에서 구현한 4가지 AI 모델의 성능을 통합 모니터링하는 **React 기반 대시보드**를
개인적으로 대폭 개선하였습니다.

| 항목 | 팀 프로젝트 (원본) | 개인 수정 후 (현재) |
|------|-------------------|-------------------|
| 파일 구조 | 단일 App.jsx (481줄) | **59개 파일 모듈 아키텍처** (~4,000줄) |
| 스타일링 | 인라인 스타일 100% | **CSS Modules + CSS 변수 테마** |
| 라우팅 | useState 기반 | **React Router (URL 동기화, 뒤로가기)** |
| 차트 | 단순 SVG polyline | **Recharts (Area/Radar/Bar/Line + 인터랙티브 툴팁)** |
| 알림 | 하드코딩 6개 | **실시간 생성 + Toast 팝업 + LIVE 인디케이터** |
| 설정 | "개발 중" 플레이스홀더 | **다크/라이트 테마, 알림 임계값, 언어 전환 (localStorage 영속)** |
| 다국어 | 없음 | **한국어/영어 150키 완전 번역 (i18n)** |
| 검색 | 없음 | **Cmd+K 글로벌 커맨드 팔레트 (퍼지 매칭)** |
| 모델 히스토리 | 없음 | **20에폭 학습 곡선 시각화 + 모델 비교** |
| PDF 리포트 | 없음 | **모듈별/전체 리포트 인쇄** |
| 이미지 | 22MB PNG | **3.5MB WebP (84% 절감)** |
| 성능 | 최적화 없음 | **React.memo, 코드 스플리팅, Error Boundary** |
