## 2. 왜 이 주제를 선택했는가?

### 2.1 제조업이 직면한 현실적 위기

대한민국 제조업은 GDP의 약 25%를 차지하는 핵심 산업이지만, 현재 세 가지 구조적 위기에 직면해 있습니다.

**첫째, 생산인구 감소와 숙련공 은퇴입니다.** 통계청에 따르면 한국의 생산가능인구(15~64세)는 2020년 3,738만 명에서 2030년 3,395만 명으로 약 343만 명이 줄어들 전망입니다. 제조 현장에서 수십 년간 경험을 쌓아온 품질 검사 숙련공들이 은퇴하면서, 그들의 눈과 손에 의존하던 육안 검사 체계가 근본적으로 흔들리고 있습니다.

**둘째, 수작업 품질 검사의 한계입니다.** 사람의 눈에 의존하는 품질 검사는 피로도, 주관적 판단, 속도 제한이라는 태생적 한계를 갖고 있습니다. 교대 근무 8시간 동안 검사원의 집중력은 시간이 지남에 따라 현저히 저하되며, 동일한 제품이라도 검사자에 따라 판정이 달라지는 일관성 문제가 발생합니다.

**셋째, 글로벌 품질 경쟁의 심화입니다.** BMW, 지멘스 등 글로벌 제조 기업들은 이미 AI 기반 품질 검사 시스템을 도입하여 불량률을 획기적으로 줄이고 있습니다. 국내 기업들이 이 흐름에 뒤처지면 글로벌 공급망에서 경쟁력을 잃게 됩니다.

### 2.2 정부 정책과의 연계

중소벤처기업부는 2026년까지 스마트공장 3만 개소 구축을 목표로 추진 중이며, 기초 단계(4,000만 원 지원)부터 고도화 단계(3억 원 지원)까지 체계적인 지원 사업을 운영하고 있습니다. 스마트 제조 도입의 가장 큰 목적은 생산 효율성 향상(56.5%)과 품질 개선(37.1%)으로, 본 프로젝트의 방향성과 정확히 일치합니다.

### 2.3 수업 내용과의 직접적 연결

본 프로젝트는 K-Digital Training 딥러닝 과정에서 학습한 핵심 기술들을 실제 산업 문제에 적용하는 것을 목표로 합니다.

| 수업 내용                                       | 프로젝트 적용                 |
| ----------------------------------------------- | ----------------------------- |
| CNN 이미지 분류 (ResNet, VGG, 전이학습)         | 주조 제품 불량/정상 자동 분류 |

| BERT 파인튜닝 / LSTM (텍스트 분류, 토큰화)      | 설비 고장 유형 예측           |

## 3. 프로젝트를 통해 얻을 수 있는 가치 및 인사이트

### 3.1 기술적 가치

**다양한 딥러닝 기법의 통합 경험**

하나의 도메인(제조) 안에서 이미지 분류, 세그먼테이션, 객체 탐지, 자연어 처리라는 4가지 서로 다른 딥러닝 접근 방식을 동시에 경험합니다. 이를 통해 "어떤 문제에 어떤 기법을 적용해야 하는가"에 대한 실전적 판단력을 기를 수 있습니다.

| 문제 유형                           | 적합한 기법        | 본 프로젝트 적용 |
| ----------------------------------- | ------------------ | ---------------- |
| "이 제품은 불량인가 정상인가?"      | CNN 이미지 분류    | 소주제 A         |
| "결함이 정확히 어디에 있는가?"      | U-Net 세그먼테이션 | 소주제 B         |
| "이미지 안에 어떤 결함들이 있는가?" | YOLO 객체 탐지     | 소주제 C         |
| "이 설비는 왜 고장났는가?"          | NLP 텍스트 분류    | 소주제 D         |

**전이학습의 산업적 효용 검증**

ImageNet으로 사전학습된 ResNet/VGG 모델을 제조 도메인에 파인튜닝하여, 적은 데이터로도 높은 정확도를 달성할 수 있는지 실험합니다. 이는 데이터 확보가 어려운 중소 제조업체에서 AI를 도입할 때 가장 현실적인 전략입니다.

**설명 가능한 AI(XAI)의 가능성**

Grad-CAM 히트맵을 통해 "AI가 어디를 보고 불량이라고 판단했는지"를 시각적으로 보여줍니다. 이는 품질 검사원이 AI의 판정 결과를 신뢰하고 수용하기 위한 핵심 요소입니다.

### 3.2 비즈니스 가치

**비용 절감 효과**

AI 비전 검사 시스템을 도입하면 24시간 무인 운영이 가능하여 인건비를 절감하고, 불량 유출로 인한 클레임 비용과 리콜 비용을 사전에 차단할 수 있습니다.

**생산성 향상**

수작업 대비 검사 속도가 10배 이상 빨라지며, 일관된 품질 기준으로 판정하므로 검사자 간 편차가 사라집니다.

**예지보전을 통한 가동률 향상**

설비 고장을 사전에 예측하여 계획된 시점에 정비를 수행함으로써, 비계획 정지 시간을 30~50% 줄일 수 있습니다.

### 3.3 학습 인사이트

본 프로젝트를 수행하면서 다음과 같은 인사이트를 얻을 수 있습니다.

- **데이터 품질의 중요성**: 실제 제조 데이터는 클래스 불균형, 촬영 조건 변화, 라벨링 노이즈 등 교과서적이지 않은 문제들이 존재하며, 이를 어떻게 처리하느냐가 모델 성능을 좌우합니다.
- **평가 지표의 의미**: 단순 Accuracy가 아닌, Precision/Recall/F1-Score/mAP/Dice 등 과제별로 적합한 평가 지표를 선택하는 판단력을 기릅니다.
- **도메인 지식의 필요성**: "어떤 결함이 치명적이고, 어떤 것은 허용 가능한가"와 같은 제조 도메인 지식이 모델 설계와 임계값 설정에 직접 영향을 미칩니다.

### 4.3 소주제별 정량적 목표 지표

#### 소주제 A. 주조 제품 불량 분류 (CNN)

| 지표                   | Before (수작업) |     After (AI)     |      개선 효과      |
| ---------------------- | :-------------: | :-----------------: | :------------------: |
| 분류 정확도 (Accuracy) |     80~85%     | **95%+ 목표** |       +10~15%p       |
| 검사 속도              |     20초/개     |      0.1초/개      | **200배** 향상 |
| 검사자 간 편차         |      ±15%      |         0%         |      완전 제거      |
| 일일 검사량            |  ~1,400개 (8h)  |   ~86,400개 (24h)   | **60배** 증가 |

모델 성능 평가 기준:

- Accuracy ≥ 95%
- Precision ≥ 93% (정상 제품을 불량으로 잘못 판정하면 → 불필요한 폐기 비용)
- Recall ≥ 97% (불량 제품을 정상으로 놓치면 → 고객 클레임, 리콜)
- F1-Score ≥ 95%

## 7. 기대 효과 종합

### 7.1 정량적 기대 효과 요약

```
                        Before (수작업)              After (AI)
                    ┌─────────────────────┐    ┌─────────────────────┐
  검사 정확도        │      80~85%         │ →  │      95~99%         │
  검사 속도          │    10~30초/개        │ →  │    0.1~0.5초/개      │
  일일 검사량        │    ~1,400개/일       │ →  │   ~86,400개/일       │
  불량 유출률        │      15~20%         │ →  │       1~5%          │
  검사 일관성        │    검사자별 편차 大   │ →  │     편차 0%          │
  설비 정지 시간     │    연 110시간        │ →  │    연 55~77시간      │
  운영 시간          │     8시간/일         │ →  │     24시간/일        │
                    └─────────────────────┘    └─────────────────────┘
```

### 7.2 정성적 기대 효과

- **숙련공 의존도 탈피**: AI가 일관된 품질 기준을 제공하여, 신입 작업자도 즉시 품질 관리 업무 수행 가능
- **데이터 기반 의사결정**: 감에 의존하던 품질 판정을 수치와 근거에 기반한 의사결정으로 전환
- **예방적 품질 관리**: 불량이 발생한 후 대응하는 방식에서, 불량 발생 전에 원인을 예측하고 예방하는 체계로 전환
- **글로벌 경쟁력 확보**: AI 품질 검사 시스템은 ISO 등 국제 품질 인증 시 가산점 요소로 작용
