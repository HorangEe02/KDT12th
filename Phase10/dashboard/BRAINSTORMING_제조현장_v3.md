# FORGE SENTINEL — 실제 제조 현장 적용을 위한 브레인스토밍 (v3)

> 현재 대시보드를 국내 제조업 현장에서 실사용하기 위해 필요한 기능 분석

---

## 현재 상태 진단

**현재 대시보드는 "AI 모델 성과 쇼케이스"** 수준이며, 실제 공장에서 운용하려면
**데이터 연동, 사용자 관리, 업무 프로세스**라는 3대 축이 필요합니다.

```
현재 상태                          실제 제조 현장 요구
─────────────────────────────────────────────────────────
시뮬레이션 데이터 (랜덤)    →    PLC/센서/카메라 실시간 연동
누구나 접근 가능             →    교대 근무자 로그인 + 권한 관리
알림이 자동 소멸             →    확인/조치/에스컬레이션 워크플로우
정적 모델 수치               →    실시간 추론 결과 + 배치 이력
설정이 브라우저에만 저장      →    서버 DB에 영구 보관 (감사 추적)
영어 혼재 UI                 →    완전 한글 UI (현장 작업자 대응)
```

## 1. 필수 기능 — 없으면 현장 투입 불가

### 1-1. 사용자 인증 + 역할 기반 접근 제어 (RBAC)

| 역할 | 접근 범위 | 예시 |
|------|----------|------|
| 작업자 | 대시보드 조회, 알림 확인 | 라인 A 교대 1조 김OO |
| 품질검사원 | + 모델 상세, 불량 이미지 확인 | QC팀 박OO |
| 라인관장 | + 설정 변경, 리포트 생성 | 생산1과 이OO |
| 공장장 | + 전체 라인 비교, 경영 지표 | 제조본부장 최OO |
| 시스템관리자 | + 모델 배포, 시스템 설정 | IT팀 정OO |

**필요 구현:**
- 로그인 페이지 (사원번호 + 비밀번호 또는 사원증 RFID)
- JWT 토큰 기반 세션 관리
- 역할별 메뉴/기능 표시 제한
- 로그인/로그아웃 시간 기록 (감사 로그)

---

### 1-2. 실시간 데이터 연동 (PLC / 센서 / MES)

현재 `useSimStream` 훅이 랜덤 데이터를 생성하는 부분을 실제 데이터 소스로 교체

| 데이터 소스 | 프로토콜 | 대상 지표 |
|------------|----------|----------|
| PLC (시멘스/미쓰비시) | OPC-UA | 설비 가동 상태, 생산 카운트 |
| 비전 카메라 | REST API / MQTT | 불량 검출 결과, 검출 이미지 |
| 온도/진동 센서 | MQTT | 설비 건강도, 이상 징후 |
| MES | REST API | 작업 지시, 배치 번호, 제품 코드 |
| ERP (SAP 등) | REST API | 자재, 재고, 원가 |

**필요 구현:**
- WebSocket 연결 레이어 (실시간 스트리밍)
- MQTT 클라이언트 (IoT 센서 데이터)
- 연결 끊김 시 자동 재연결 + 데이터 버퍼링
- 데이터 정규화 미들웨어 (단위 변환, 타임존)

---

### 1-3. 데이터베이스 + 백엔드 API

| 계층 | 기술 선택지 | 역할 |
|------|-----------|------|
| 백엔드 | Node.js (Express) / Python (FastAPI) | REST API, 인증, 비즈니스 로직 |
| RDBMS | PostgreSQL | 사용자, 배치, 알림, 감사 로그 |
| 시계열 DB | InfluxDB / TimescaleDB | 센서 데이터, 생산 추이 |
| 캐시 | Redis | 세션, 실시간 대시보드 데이터 |
| 파일 스토리지 | MinIO / S3 | 불량 검출 이미지, 리포트 PDF |

### 1-4. 알림 확인/조치 워크플로우

현재: 알림이 5초마다 생성되고 자동 소멸 → 현장에서는 **절대 안 됨**

```
[불량 감지] → [알림 생성] → [작업자 확인] → [조치 입력] → [완료]
                              │ 5분 무응답           │ 해결 불가
                              ↓                     ↓
                         [라인관장 에스컬레이션]  [품질팀 이관]
                              │ 15분 무응답
                              ↓
                         [공장장 긴급 알림 (SMS)]
```

**필요 구현:**
- 알림 상태 머신: `생성 → 확인 → 조치중 → 완료 / 이관`
- 확인 버튼 (누가, 언제 확인했는지 기록)
- 조치 내용 입력 폼 (텍스트 + 이미지 첨부)
- 에스컬레이션 타이머 (미확인 시 자동 상위 통보)
- SMS/카카오톡 알림 연동 (긴급 시)

### 1-5. 교대 근무 관리

| 교대 | 시간 | 인원 |
|------|------|------|
| 1조 (주간) | 06:00~14:00 | 작업자 3명 + 검사원 1명 |
| 2조 (오후) | 14:00~22:00 | 작업자 3명 + 검사원 1명 |
| 3조 (야간) | 22:00~06:00 | 작업자 2명 + 검사원 1명 |

**필요 구현:**
- 교대 시작/종료 체크인 화면
- 교대 인수인계 체크리스트 (이전 교대 이슈 전달)
- 교대별 성과 지표 (수율, 불량률, 가동률)
- 교대 리포트 자동 생성

## 2. 중요 기능 — 운영 효율을 크게 높임

### 2-1. 배치/로트 추적 (Traceability)
- 제품 배치 번호 ↔ 불량 알림 ↔ 원인 분석 연결
- "이 제품은 언제, 어느 라인에서, 누가 검사했는가" 추적
- ISO9001 / IATF16949 (자동차) 인증 필수 요소

### 2-2. OEE (설비종합효율) 대시보드
```
OEE = 가동률 × 성능률 × 양품률

가동률: 계획 가동 시간 중 실제 가동 시간 비율
성능률: 이론 사이클 타임 대비 실제 생산 속도
양품률: 총 생산량 중 양품 비율
```
- 라인별/설비별 OEE 실시간 표시
- 목표 대비 달성률 게이지
- 6대 로스(Big Six Losses) 분석

### 2-3. SPC (통계적 공정 관리) 차트
- X-bar / R 관리도 (치수 관리)
- p 관리도 (불량률 관리)
- 관리 한계선 (UCL/LCL) 자동 계산
- 이상 패턴 자동 감지 (연속 7점 상승 등)

### 2-4. 불량 이미지 증거 관리
- AI가 불량 감지 시 자동 캡처
- 알림 상세 화면에서 원본 이미지 확인
- 불량 유형별 이미지 갤러리 (학습 데이터 재활용)
- 작업자가 직접 촬영한 이미지 업로드 기능

### 2-5. 설비 예지보전 실시간 연동
- 현재 DistilBERT 모델의 예측 결과를 실제 표시
- 설비별 건강도 점수 (0~100)
- 정비 일정 자동 추천
- 정비 이력 관리 (누가, 언제, 무엇을 교체)

## 5. 요약

**현재 대시보드의 한글화는 완전히 해결되었으며 (150키, 한/영 즉시 전환),
실제 제조 현장에서 쓰려면 다음 3가지가 여전히 필요합니다:**

1. **사람** — 누가 로그인해서 어떤 조치를 했는지 (인증 + 감사 추적)
2. **데이터** — 진짜 설비에서 오는 실시간 수치 (PLC/센서 연동)
3. **프로세스** — 알림 → 확인 → 조치 → 완료의 업무 흐름 (워크플로우)

**한글화 완료로 현장 작업자의 즉각적 이해도가 확보되었으며,
다음 단계는 알림 확인 버튼(B)과 교대 UI(C) 같은 프론트엔드 기능 추가가 가장 효과적입니다.**
